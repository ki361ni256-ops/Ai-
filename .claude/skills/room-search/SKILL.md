# ROOM 商品さがし → 紹介文づくり

本人は「商品名」と「紹介文」をコピペして ROOM に投稿するだけ、にするためのしくみ。
本人が言った言葉（例:「おしゃれな上着」）から、商品さがし・レビュー確認・紹介文・ハッシュタグまでを一度で返す。

## 前提
- 楽天市場のサイト（search / item / review）は、この環境からは楽天側のボット対策でブロックされて読めない（2026-10-05 確認）。**公式API（楽天ウェブサービス 商品検索API）を使う**
  - 環境変数 `RAKUTEN_APP_ID`（必須）・`RAKUTEN_ACCESS_KEY`（発行されていれば）
  - ネットワーク設定で `app.rakuten.co.jp` を許可（新しいエンドポイントに変わっていたら `RAKUTEN_API_ENDPOINT` で指定し、そのドメインも許可）
  - 未設定・失敗のときは、そのことと設定のしかたを本人に伝えて止まる（推測で商品を作らない）
- **APIではレビュー本文は取れない**。取れるのは商品名・価格・レビュー平均・件数・商品説明・URL。レビューの中身を入れたいときは、本人に商品ページのレビューを数件コピーして貼ってもらう
- 作業前に `02_plan/strategy.md`（読者・本人の事実）、`guidelines/review-summary.md`、`guidelines/compliance.md` を読む

## 手順
1. **条件を決める**: 本人の言葉からキーワードを作る。価格・性別・サイズなど、聞かないと選べない条件があるときだけ1回聞く。なければ「子育て世帯のパパママが普段使いしやすいもの」を前提にする
2. **探す**: `python3 tools/rakuten_search.py "<キーワード>" 20` を実行し（レビュー件数の多い順・在庫ありで返る）、候補を3つ選ぶ
   - 目安: ★4.0以上・レビュー50件以上・在庫あり
   - 価格帯をばらす（手ごろ／中くらい／少し高め）
3. **中身をまとめる**: 商品説明（素材・サイズ・機能）と、レビュー平均・件数をもとに特徴を2〜3個にまとめる。本人がレビューを貼ってくれたときは、★の高い声と低い声の両方から、多かった声と不満をまとめる
4. **紹介文を書く**（`guidelines/review-summary.md` のルール）
   - 1行目で、誰のどんな悩みに合うか
   - レビューを読んだときだけ「レビューでは〜という声が多い」と書く（読んでいないレビューの中身は書かない）。読んでいないときは「★4.5・1,200件と評価が高い」のように数字だけ使う。レビューの文章はそのまま写さない
   - 本人が使っていない商品なので、「使ってみた」「買ってよかった」「わが家では」は書かない。本人が「持っている」と言ったときだけ体験を書く（`strategy.md` の本人の事実にあること）
   - 良い点2つ（＋レビューを読んだときは気になる点1つ）、3〜5行、120文字前後、絵文字1〜2個
   - 効果効能（痩せる・治る・肌がきれいに 等）は書かない
   - 最後に PR 表記「※楽天アフィリエイトを利用しています」（`CLAUDE.md` の作業ルールが変わったらそれに従う）
5. **ハッシュタグ**: 5〜8個。商品名・種類・使う場面・悩みのことばを混ぜる
6. **チェック**: 書いたものを `rakuten-checker` の観点（体験の捏造・効果効能・断定表現・PR表記）で自分で見直す
7. **保存**: 候補ごとに `03_posts/_search/YYYY-MM-DD_キーワード.md` にまとめて保存し、`02_plan/product-list.md` に「候補」として追加。commit して push する

## 返し方（チャット）
商品ごとに、次の形でコピペしやすく返す。前置きは短く。

```
### ① （ひとことで特徴）
価格 〇〇円 ／ ★4.5（1,234件）／ ショップ名 ／ 確認日 YYYY-MM-DD
楽天のページ: URL
```
**ROOMで検索する商品名**（ROOMの投稿画面で検索するときに貼る。ブランド名＋品名など、検索で見つかりやすい短い形）
```
（商品名）
```
**紹介文＋ハッシュタグ**
```
（紹介文）
※楽天アフィリエイトを利用しています
#〜 #〜
```

最後に一言だけ添える:「ROOMで検索したら、ショップ名と値段が同じものを選んでください」

## やらないこと
- 開けなかったページの内容を想像で書く
- レビューを丸写しする
- 価格・★・件数を確認日なしで書く
