# Threads 投稿づくり

本人は、日常で起きたことを「ネタ：〜」とひとこと送るだけ。週1回「1週間分作って」でまとめて受け取り、Threads の予約投稿に入れる。

## 必ず読むもの
- `CLAUDE.md` の「Threads 投稿の書き方」（最優先）
- `02_plan/strategy.md` の「本人の事実」
- `スレッズ投稿/普段の投稿とコメントの型.md`
- `スレッズ投稿/ネタ帳.md`

## A. ネタを受け取ったとき（「ネタ：〇〇」）
1. `スレッズ投稿/ネタ帳.md` の「未使用」に日付つきで追記する（本人の言葉をそのまま）
2. そのネタで投稿を1本作り、`スレッズ投稿/YYYY-MM-DD_内容.md`（`_template.md` の形）に保存
3. チャットには本文とコメント欄をコピペできる形で返す
4. ネタ帳のそのネタを「使用済み」に移す。commit して push

## B. 「1週間分作って」
1. ネタ帳の「未使用」から選び、`普段の投稿とコメントの型.md` の「1日の投稿」（朝・昼・夜の1日3本。昼は男性向け）に沿って21本作る。本人が「1日〇本で」と言ったらそれに合わせる
2. ネタが足りないときは、`strategy.md` の本人の事実だけで作れる投稿で埋める。それでも足りなければ、足りない本数と「こんなネタがあれば作れる」を伝える（体験を作らない）
3. 商品・ROOMにつなげるのは週4本まで。つなげる投稿はコメント欄にPR表記
4. 1本ずつファイルに保存し、チャットには「1日目 朝・昼・夜」の順で本文とコメント欄を返す
5. 最後に予約投稿の時間の目安を添える（朝の通勤時間・夜の寝かしつけ後など、本人の生活に合う時間）
6. commit して push

## 返し方
```
### 1日目（種類）
本文
（コードブロック）
コメント欄
（コードブロック）
```
想像で補った部分があれば、各投稿の下に「⚠️ 確認：〇〇は想像です」と1行で書く（なるべく作らない）。

## やらないこと
- 本人の事実にない体験・数字を作る
- 健康・医療の効果を言い切る
- 他人への返信文を作る（Geminiで作る運用）
