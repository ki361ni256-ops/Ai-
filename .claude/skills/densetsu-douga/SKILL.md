# 都市伝説動画の制作フロー

詳しい体制と決まりは `都市伝説チャンネル/README.md`。

## 流れ（担当は .claude/agents/densetsu-*.md）
1. テーマ・形式（ショート／長尺。指定なしはショート）を確認。テーマがなければ企画担当に3案出させて本人に選んでもらう
2. slug（英小文字とハイフン。例 `kisaragi-station`）を決め、`都市伝説チャンネル/作品/<YYYYMMDD>_<slug>/` を作る
3. 順番に担当を呼ぶ。前の担当のファイルを読ませる
   1. densetsu-planner → 01_企画.md
   2. densetsu-researcher → 02_リサーチ.md
   3. densetsu-writer → 03_台本.md
   4. densetsu-director → 04_演出.md
   5. densetsu-checker → 05_チェック.md
   6. densetsu-editor → 06_編集長判断.md
4. チェックが「要修正」「NG」なら、編集長の指示どおり該当担当にやり直させ、チェックからやり直す（最大2周。それでも通らなければ本人に相談）
5. 本人には「タイトル・台本・サムネ案・チェック結果の要点・開示が必要か」を短く返す
6. commit・push する

## 守ること
- リサーチで確認できないことを事実として台本に入れない
- 公開・投稿は本人が行う（自動投稿しない）
