# ちいかわ えいごランド

ちいかわたちと いっしょに えいごを まなぶ、こども向けの 学習アプリ(1まいの HTML)。
`ちいかわ がくしゅうランド` と おなじ 見た目・しくみ(きょうの 3つ、ポイント、シール、にがて ふくしゅう、おうちの ひとへ)で 作っている。

- アプリ本体：`ちいかわえいご/index.html`(`python3 ちいかわえいご/src/build.py` で 作りなおす)
- 中身を 直すときは `ちいかわえいご/src/` を 直す
  - `data.js`：ことば・アルファベット・ぶん・えほん
  - `app.html`：画面と しくみ
  - `chars.js`：なかまの え(ちいかわ がくしゅうランドと おなじ 描きかた)

## 1日の ながれ(ポイントと おこづかい)
- ミッション3つで 1日20ポイント:🗺️ すすむコース 1ステップ(10。6わり いじょうで 7、8わり いじょうで 10、おなじ日に やりなおして 10に ふやせる)/📖 えほん 1さつ(5)/🎲 すきな メニュー 1かい(5。5わり みまんは 3)
- げつ〜にちで 100ポイント(5日 ぜんぶ)なら おこづかい 100えん(金額は おうちの ひと画面で かえられる)。とちゅうで やめた しゅうは 0えん
- ミッションが おわった あとの べんきょうは ⭐(あそび用・上限なし)になる
- おうちの ひと画面で、きょうの ポイントの てなおし、6しゅうぶんの きろくが 見られる

## すすむコース(30ユニット)
1ユニット = ① まなぶ(1語ずつ きいて まねして いう)→ ② れんしゅう(クイズ。前の ユニットの ことばも まぜる)→ ③ はなそう(しつもんを きいて こたえる かいわ+こえに だす)。
あいさつ・いろ・かず から はじまり、ようび・つき・きょうか・まち・しごと・「What do you want to be?」まで。

## できること
| メニュー | 学年 | 内容 |
|---|---|---|
| きいて えらぼう | ようじ〜 | えいごを きいて、あう えを えらぶ |
| ABC と おと | ようじ〜 | おおもじ・こもじ、ことばの はじめの おと |
| まねして いおう | ようじ〜 | きいた えいごを こえに だす |
| えいごで なんて いう? / いみ クイズ | 小3〜 | えと にほんご ⇄ えいご |
| スペル パズル | 小3〜 | もじを ならべて ことばを つくる |
| ぶんを つくろう / きいて わかる | 小3〜 | えいごの ぶんを ならべる・きいて いみを えらぶ |
| かいわ | ようじ〜 | しつもんを きいて こたえを えらび、こえに だす(ひらいた ユニットの かいわ) |
| えほん | ぜんぶ | ちいかわたちの みじかい えいごの おはなし(ことばを おすと いみ) |
| たんご ずかん | ぜんぶ | 約260語。おすと えいごで よむ |

- きょうの 3つ(レッスン・えほん・おすすめ)、ポイント(1日20・1しゅう100が めあて)、シール、ランク
- まちがえた もんだいは「にがて」へ、せいかいした もんだいは 1・3・7・14・30日あとに ふくしゅう
- きょうだいごとの きろく、おうちの ひと用の きろく・せってい(かけざんの かぎ つき)
- きろくは 端末と claude.ai アカウントの 両方に ほぞん

## 注意
- ちいかわの キャラクターは ナガノ さんの 作品。家庭で つかう ためだけの アプリとして 作っている。公開・配布・販売は しない
- 英語は アメリカ英語で そろえている(fall・soccer・pants など)。よみあげは 端末に 入っている 音声(アメリカ/イギリスを えらべる)。ネイティブの 人の 録音は まだ 入って いない
- 「はなす」ボタン(発音チェック)は、index.html を ブラウザで ちょくせつ ひらいた ときだけ 出る。claude.ai の ページでは マイクが つかえないので 出さず、こえに だして いえたら「いえた!」を おして すすむ
