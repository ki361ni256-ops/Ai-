# ちいかわ えいごランド マーケティング計画

作成：マーケティング担当（eigo-marketing） / 確認日：2026-10-21

## 0. 前提と書き方のルール

- **いま**：代表の家庭（7歳・小1の娘さん、英語ははじめて）で使うためだけのアプリ。ちいかわは ナガノさんの作品なので、**キャラクターを使ったままの販売・配布・広告は計画しない**。外に出す案（3章）は、すべて**オリジナルキャラクターに差し替えてから**の話。
- **めざすこと**：小1〜小6まで飽きずに毎日つづけて、くり返しで英語を話せるようになる。英検5級からはじめて、将来、英語を重視する入試を選べる状態にする。
- **ポイントのしくみ（いまのアプリ）**：1日20ポイント（すすむコース10・えほん5・すきなメニュー5）。月〜日で100ポイントなら おこづかい100円（金額は「おうちの ひとへ」で変えられる）。
  - 20×5＝100 なので、**週に2日は休んでも100に届く**。この「2日の余白」は大事なので、こわさない（2章で根拠を書く）。
- **出典**：数字や他社の情報には出典URLと確認日をつけた。確認できなかったものは書いていない。
  - 確認方法の注意：この作業環境からは多くのサイトを直接開けなかった（接続が拒否された）。そこで Apple の審査ガイドラインは本文を直接読み、**それ以外は検索エンジンの結果に出た公式ページの抜粋で確認した**。数字を外向けに使う前には、もう一度ページ本文を開いて確かめること。
  - 他社の数字は**その会社が自分で発表したもの**がほとんど。第三者による検証ではない。
- **約束しないこと**：売上・ダウンロード数・英検合格・「話せるようになる時期」は約束しない。

## 1. いちばん大事な指標と、家庭でつづける工夫

### 1-1. 指標（毎週日曜の夜に、代表が見る）

| 順位 | 指標 | はかり方 | 見る場所 |
|---|---|---|---|
| ★1 | **自分から開いた日数（週）** | 声をかける前に自分で開いた日に、親が紙のカレンダーに ○ をつける | 紙のカレンダー（アプリにはまだ記録がない → 4章でアプリに追加する案） |
| ★1 | **開いた日数（週）** | 0〜7日 | 「おうちの ひとへ」の 週の表・れんぞく日数 |
| 2 | **週100ポイント 達成（はい／いいえ）** と、連続で達成した週の数 | 「おうちの ひとへ」の 6週ぶんの表 | アプリ |
| 3 | こえに だした かいすう（週） | 「おうちの ひとへ」のタイル | アプリ |
| 4 | にがての のこり数 | ふえつづけていないか | アプリ |
| 5 | 本人の ひとこと | 「きょう いちばん たのしかったのは？」の答えをメモ | 紙 |

- **目安の考え方**：最初の4週間は「週5日開く」と「自分から開く日がふえていくか」だけを見る。正答率やポイントは二の次。
  - 根拠：Duolingo は、1日の目標が高い人ほど連続（ストリーク）が途切れやすく、「1レッスンだけで連続が伸びる」形に変えたら Day14 の継続率が 3.3% 上がった、と自社ブログで発表している（A/Bテスト。出典：https://blog.duolingo.com/improving-the-streak/ 、2020-11-19 掲載、確認日 2026-10-21）。**はじめは量より「毎日ちょっと」**。
- **黄色信号**（どれか1つで 4章の「てこ入れ」を検討）
  - 2週つづけて 開いた日が4日以下
  - 「やりたくない」が週2回以上
  - 自分から開いた日が 3週たっても0のまま

### 1-2. しかけ（家の中で、きょうから試せる）

1. **時間と場所を1つに決める（いつもの合図）**
   「朝ごはんの あと、リビングの いすで」「おふろの 前に」など、**毎日おなじ前後の行動にくっつける**。Duolingo も「同じ状況で何度もくり返すと、自動的にやるようになる」という習慣の研究を、連続日数の設計の根拠にしている（出典：https://blog.duolingo.com/how-duolingo-streak-builds-habit/ 、確認日 2026-10-21）。
2. **タブレットを その場所に置いておく**（ホーム画面のいちばん目立つ所にアイコン）。開くまでの手間を減らす。
3. **紙のカレンダーを冷蔵庫に**：開いた日に本人がシールを貼る（アプリのシールちょうとは別に、目に見える場所に）。自分から開いた日は ちがう色のシール。
4. **1日の最低ラインは「すすむコース1つ（10ポイント）」**。えほん・すきなメニューは「できたら」。つかれている日は「コースだけで えらい」とはっきり言う。
5. **えほんは親子で音読**：えほん（いま9話）は、親が先に読む→子がまねる→子が先に読む、の順。英検5級のスピーキングテストは「20語程度の文を音読して、質問に答える」形式なので（出典：https://www.eiken.or.jp/eiken/exam/4s5s/ 、確認日 2026-10-21）、えほんの音読はそのまま練習になる。
6. **月曜の朝に「こんしゅうの ポイント」画面を一緒に見る**。「5日で100になるよ。どの2日を おやすみに する？」と**本人に休む日を決めさせる**（自分で決めた計画は守りやすい。休む日を先に決めると、休んでも罪悪感が出にくい）。

### 1-3. 声かけ（言う／言わない）

| 場面 | 言う | 言わない |
|---|---|---|
| はじめる前 | 「きょうの ユニット、なにかな？」 | 「早く英語やりなさい」 |
| おわった時 | 「"apple" の いいかた、ほんものみたいだった」（**具体的に、やり方をほめる**） | 「えらいね」だけ／「100円まであと少し」だけ |
| まちがえた時 | 「にがてに 入ったね。ちいかわたちが あとで また 出してくれるよ」 | 「ちがうでしょ」 |
| 休んだ時 | 「きょうは おやすみの日に しよう。あした コースだけ やろう」 | 「れんぞくが 切れちゃったね」 |
| 夕食の時 | 「きょう おぼえた英語、ひとつ 教えて？」（**子が先生役**） | テストのように聞く |

- ポイント：**外に話す場面を毎日1回つくる**（夕食で1語・1文）。アプリの外で使うことで「話す」につながる。

### 1-4. ごほうび（おこづかい100円）の使い方

- **注意点（研究より）**：前もって約束された形のあるごほうび（お金・物）は、子どもの「やりたい気持ち」を下げることがある、という研究のまとめがある。いっぽう、**内容のある前向きな声かけ（ほめ言葉）は やる気を高めた**、とも報告されている（Deci, Koestner, Ryan 1999, Psychological Bulletin 125(6), 627–668。https://depts.washington.edu/techdocs/papers/deciExtrinsicRewardsAndIntrinsicMotivation99.pdf 、確認日 2026-10-21）。この点は研究者の間で議論が続いているので、「お金はダメ」ではなく「**お金だけにしない**」と考える。
- そこで、おこづかいは次のように使う：
  1. **週1回・日曜の夜にまとめて渡す**（毎回渡さない）。渡すときは金額より「今週できるようになった英語」を一緒に言う。
  2. **ことばのごほうびを主役に**：毎日の「具体的にほめる」（1-3）を先に。
  3. **おこづかいとは別の「ことばのごほうび」**：週100を達成した週は、娘さんが「えいごの先生」になって、家族に英語を1つ教える時間をつくる（物やお金ではない楽しみ）。
  4. **100に届かない週の扱い**：アプリは「とちゅうでやめた週は0円」としている。ここは変えないが、「来週の月曜からまた0からスタート」とあっさり言う。責めない。
  5. **金額は上げすぎない**。学年が上がって ユニットが難しくなった時に、金額ではなく「ごほうびの中身」（えらべる週末の英語あそびなど）を変える。

## 3. 将来、外に出す（販売する）場合の計画

> この章は「もし外に出すなら」の計画。いまは家庭用のまま。外に出すかどうかは代表が決める。

### 3-1. やる順番（決める → 作る → 確かめる → 出す）

1. **キャラクターの差し替え**（これが終わるまで、外には一切出さない）
   - ちいかわ・ハチワレ・うさぎ などの絵（`src/chars.js`）、名前、えほんの話（`src/data.js` の STORIES）、セリフ、アプリ名「ちいかわ」をすべて取り除く。
   - オリジナルキャラクターは、**ちいかわに似せない**（形・色・口ぐせ）。作るのは代表 or 依頼したイラストレーター。依頼する場合は**著作権の譲渡か利用許諾を契約書で決める**。
   - アプリ名も新しく。App Store の名前は30文字まで、ほかのアプリ名や商標を並べない決まりがある（Apple 審査ガイドライン 2.3.7、https://developer.apple.com/app-store/review/guidelines/ 、確認日 2026-10-21）。
2. **ネイティブ音声の用意**
   - いまは端末に入っている音声で読み上げている。読み上げの声は**端末とブラウザによって変わる**（MDN、https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices 、確認日 2026-10-21）ので、売り物では品質がそろわない。
   - 選択肢（どれも費用は見積もりを取ってから決める。ここでは数字を書かない）
     - a. **ネイティブ話者に録音を依頼**：約260語＋文＋えほん。録音の利用範囲（アプリ内・広告・期間）を契約で決める。子どもに聞かせるので、ゆっくり版と ふつう版の2種類。
     - b. **商用利用できる音声合成サービス**：利用規約で「アプリに組み込んで配布してよいか」を必ず確認。
   - 発音チェック（いまの「まねして いおう」）は、Chrome などでは**声がサーバーに送られて認識される**（MDN、https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition 、確認日 2026-10-21）。外に出す時は、①端末の中だけで処理する方法を選ぶ、②使う前に保護者に説明して同意をもらう、のどちらかが必要。
3. **プライバシー**
   - いまは記録を「端末」と「claude.ai アカウント」の両方に保存している。外に出す時は保存先を作り直し、**何を・どこに・何のために保存するか**を決める。おすすめは「名前は ニックネームだけ、記録は端末の中だけ」から始める（集めない情報は守らなくてよい）。
   - **日本**：個人情報保護法では、同意の結果を判断できない子どもについては親などの法定代理人の同意が必要で、目安は「一般的には12歳から15歳までの年齢以下」とされている（個人情報保護委員会 Q&A、https://www.ppc.go.jp/all_faq_index/faq1-q1-62/ 、確認日 2026-10-21）。**法改正の作業が進んでいて、16歳未満を基準にする方向の資料が出ている**（https://www.ppc.go.jp/files/pdf/260916_kihonntekinakanngaekatanitsuite_1.pdf ）ので、出す時点の条文を確認する。
   - **アメリカの子どもにも届く場合**：13歳未満の子どもから個人情報を集める前に、保護者の確認できる同意が必要（COPPA。FTC、https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions 、確認日 2026-10-21）。
   - **ストアの決まり**（Apple、https://developer.apple.com/app-store/review/guidelines/ 、確認日 2026-10-21）
     - プライバシーポリシーのリンクを、ストアの情報欄とアプリの中に置く。何を集め、誰と共有し、どう消せるかを書く（5.1.1）
     - 子ども向けカテゴリ（Kids）では、外へのリンクや購入は**保護者だけが通れる関門（ペアレンタルゲート）の内側**だけ。第三者の分析ツール・広告は原則入れない（1.3、5.1.4）。いまの「かけざんの鍵」はこの考え方に近い
     - 「For Kids」などの言葉は Kids カテゴリのアプリだけが使える（2.3.8）
     - ただのウェブサイトを包んだだけのアプリは通らないことがある（4.2）
   - **Google Play**：対象に子どもが含まれるアプリは「ファミリー ポリシー」に従う必要があり、守らないと削除・停止のことがある（https://support.google.com/googleplay/android-developer/answer/9893335 、確認日 2026-10-21）。
4. **表示（特定商取引法・景品表示法）**
   - **お金をとってネットで売る＝通信販売**。広告（販売ページ）に、事業者の氏名（個人なら戸籍上の氏名）・住所・電話番号、価格、支払い方法・時期、提供時期、返品（キャンセル）についてなどを表示する。「特定商取引法に基づく表記」へのリンクを、ページの冒頭から簡単にたどれる場所に置く（消費者庁 特定商取引法ガイド、https://www.no-trouble.caa.go.jp/what/mailorder/advertising.html 、https://www.no-trouble.caa.go.jp/qa/advertising.html 、確認日 2026-10-21）。
     - 個人で売る場合、**自宅の住所・電話番号を出すことになる**点に注意。請求があればすぐ知らせる体制を書いて省略する扱い（Q&A）もあるので、出す前に条件を確認する。
     - サブスク（毎月払い）にする場合は、解約の方法も分かりやすく書く。
   - **広告で言ってはいけないこと**：「〇か月で話せる」「英検に受かる」などの効果は、**根拠となる資料を前もって持っていないと**、景品表示法の優良誤認表示として扱われることがある（不実証広告規制。消費者庁、https://www.caa.go.jp/policies/policy/representation/fair_labeling/representation_regulation/misleading_representation 、確認日 2026-10-21）。言うのは「何ができるアプリか」（機能）だけにする。
5. **届け方（案。どれを選ぶかは未定）**
   - a. **ウェブで公開（いまの1枚HTMLを生かす）**：作り直しが少ない。販売ページ＋特商法表記は自分で用意。
   - b. **App Store / Google Play**：見つけてもらいやすく、安心感がある。ただし、上の子ども向けの決まり、アプリ内課金のルール（機能の解放はアプリ内課金を使う。Apple 3.1.1）、ウェブを包んだだけでは不可（4.2）への対応が要る。
   - c. **まず知り合いの家庭で無料で試してもらう（テスト）**：オリジナルキャラ版ができたら、数家庭に4週間使ってもらい、1章の指標（自分から開いた日数・週100の達成）を見る。**外に出すかどうかは、ここで続くかを見てから決める**。
   - 宣伝の場所（SNS・ブログなど）は c の結果を見てから決める。子どもの顔・名前・声は宣伝に使わない。
6. **価格の考え方（仮説。数字は決めない）**
   - 事実：子ども向けの有名な学習アプリには、**無料・広告なし・課金なし**のものがある（Duolingo ABC、Khan Academy Kids。出典は2-1）。つまり「無料で良いもの」と比べられる。
   - 仮説1：**中身の量と「英検5級→4級…と学年に沿って続く道すじ」**がそろわない限り、お金はいただけない（B1が先）。
   - 仮説2：お金をいただくなら、子どもに見せる課金ではなく、**保護者に向けた買い切り or 月額**（子ども画面には課金を出さない）。どちらが合うかは c のテストで保護者に聞く。
   - 仮説3：「家庭のおこづかいと連動したポイント表」は、保護者にとって分かりやすい価値かもしれない（未確認。テストで聞く）。
   - 値段の数字は、費用（音声・イラスト・ストア手数料など）の見積もりと、テストでの聞き取りがそろってから決める。

### 3-2. 外に出すまでの「やってはいけない」

- ちいかわの絵・名前・お話が1つでも残ったまま、人に渡す・見せて宣伝する・売る
- 子どもの記録を、説明と同意なしにサーバーへ送る
- 効果（話せる・受かる）を広告で約束する
- 売上・ダウンロード数を見込みとして人に約束する
