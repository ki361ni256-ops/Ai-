# ちいかわ えいごランド:相談用の 仕様と 指示プロンプト

作成:2026-10-21(アプリは 2026-10-21 時点の 版)
使いかた:下の「① 相談プロンプト」を まるごと コピーして、Gemini と ChatGPT に それぞれ 貼る。もらった 回答は「② 回答を まとめて Claude に わたす プロンプト」と いっしょに Claude に 貼る。

## ① 相談プロンプト(Gemini・ChatGPT に 貼る)

````
あなたは、子ども向け英語学習アプリの 学習設計・UX・継続設計に くわしい アドバイザーです。
日本の 小学生が 毎日 自分から 続けられる 英語学習アプリを 作っています。下の「いまの仕様」と「困っていること」を 読んで、どう 改善すれば よいか アドバイスを ください。

# 目的
- 娘(7歳・小1・英語は まったく はじめて)が、小1〜小6まで 飽きずに 毎日 自分から 続けられる アプリにしたい
- 反復学習で、単語を 覚えるだけでなく、自分で 英語を 話せるように なってほしい
- 長期目標:英検5級から はじめて 4級・3級…と 進み、将来は 英語の 資格が 加点に なる 中学入試も 選べる 状態に したい
- 他の 有名な 子ども向け英語アプリ(Duolingo ABC、Khan Academy Kids など)の よいところも 取り入れたい

# 前提・変えられない 条件
- 形式:HTML 1枚の ウェブアプリ(サーバーなし)。claude.ai の「アーティファクト」(非公開リンク)として 公開し、タブレット・スマホの ブラウザで 使う
- 見た目と しくみは、家で 使っている 国語・算数アプリ「ちいかわ がくしゅうランド」と そろえる(ちいかわたちが 応援する、ポイント、シール、にがて復習、おうちの人の画面)
- ちいかわの キャラクターは 家庭内で 使う ためだけ(販売・配布・広告は しない)
- ポイントの ルール(親子で 決めたもの):1日の 上限 20ポイント。月曜〜日曜の 1週間で 100ポイント たまったら おこづかい 100円。途中で やめた 週は 0円
- 英語の 音声は 端末の 読み上げ機能(Web Speech API の speechSynthesis)。ネイティブの 人の 録音は まだ ない
- claude.ai の ページ内では マイクが 使えない(音声認識が できない)

# いまの 仕様

## 画面の ながれ
- 起動 → タップで スタート(音を 出せるように するため)→ ホーム
- ホーム:えらんだ なかま(ちいかわ・ハチワレ・うさぎ・モモンガ・くりまんじゅう・ラッコの 6人から)が 声かけ/「きょうの えいご」(ミッション 3つ)/「すすむコース」の 大きな ボタン/ぜんぶの メニュー/えほん・たんご ずかん・シールちょう/ランク/今週の ポイント/おうちの ひとへ
- 学年:ようじ・1〜6ねんせい。学年で 出る 問題の 種類が 変わる(ようじ〜2年:聞いて 選ぶ 中心/3・4年:意味・スペル・並べ替えも/5・6年:小学校の 単語と 文)
- 子どもの 画面は ひらがな・カタカナ だけ(漢字なし)。ボタンは 大きく、まちがえても 責めない 言葉

## 1日の ミッション(3つで 20ポイント)
| ミッション | ポイント |
|---|---|
| すすむコース 1ステップ | 10(⭐ 6割以上 正解で 7、8割以上で 10。同じ日に やり直して 7→10に 増やせる) |
| えほん 1さつ(読んで 最後の クイズ) | 5(1回目で 正解)/3(2回目以降で 正解) |
| すきな メニュー 1回 | 5(5割以上 正解)/3(5割未満) |
- 3つ ぜんぶで ちょうど 20。5日 やると 週 100 → おこづかい 100円(金額は 親が 変えられる)
- ミッションが 終わった あとの 学習は ⭐(遊び用・上限なし)だけ 増える
- 「100ポイントを 達成した 週が 何週 続いているか」を 表示(休みの 日が あっても 切れない)

## すすむコース(30ユニット・順番に 進む 地図)
- 1ユニット = ① まなぶ(1語ずつ 絵・英語・意味を 見て、ふつうの 速さ → ゆっくりの 2回 読み上げ。まねして 言ったら「いえた!」→ 最後に 聞いて 選ぶ 確認クイズ)→ ② れんしゅう(ユニットの 単語 5〜10語の クイズ+前の 3ユニットの 単語 2問+最後に まねして 言う 1問)→ ③ はなそう(ユニットの 会話+前の 会話 3つ を「質問を 聞いて 答えを 選ぶ」、最後に 答えを 声に 出す)
- 6割以上で 次の ステップが 開く。親の 画面で「ぜんぶの ユニットを 開く」も できる
- ユニットの 順番:あいさつ/いろ/かず1〜5/どうぶつ/かず6〜10/たべもの/からだ/かぞく/きもち/ようす/のりもの/てんき/どうぶつ2/おやつ/がっこう/うごき1/うごき2/スポーツ/いえの もの/ようび/大きな かず/きせつ/つき1〜6/つき7〜12/きょうか/まち/しごと/うごき3/ようす2/じこしょうかい
- 会話の 例:Hello! How are you? → I'm fine, thank you. / What color do you like? → I like blue. / How old are you? → I'm five. / What do you want to be? → I want to be a doctor.(30個)

## メニュー(問題の 種類)
| メニュー | 学年 | 内容 |
|---|---|---|
| きいて えらぼう | ようじ〜 | 英語を 聞いて 4つの 絵から 選ぶ |
| ABC と おと | ようじ〜 | 大文字→小文字/単語の はじめの 文字(26文字、例:a apple) |
| まねして いおう | ようじ〜 | 聞いた 英語を 声に 出して「いえた!」 |
| かいわ | ようじ〜 | 質問を 聞いて 答えを 3択で 選ぶ(ようじ〜2年は 各選択肢に 日本語訳つき) |
| えいごで なんて いう? | 3年〜 | 絵と 日本語 → 英語を 4択 |
| いみ クイズ | 3年〜 | 英単語 → 日本語を 4択 |
| スペル パズル | 3年〜 | 文字を 並べて 単語を 作る |
| ぶんを つくろう | 3年〜 | 単語を 並べて 文を 作る(2回 まちがえると 答えの ヒント) |
| きいて わかる | 3年〜 | 英文を 聞いて 意味を 選ぶ |
- 1回 8問。まちがえた 問題は 解説を 見せて、3問後に もう一度(最大2回)出す
- 正解:紙吹雪・効果音・なかまが 喜ぶ。不正解:×ではなく「おしい」と はげます

## えほん(9話・オリジナル)
- ちいかわ・ハチワレ・うさぎが 出る 短い 英語の お話(Lv1:3〜4文/Lv2:5文/Lv3:5文の 過去形)
- 単語を タップすると 意味と 発音、1文ずつ 読み上げ、ぜんぶ 読み上げ、最後に 3択クイズ

## 単語・教材の 量
- 単語 262語(20の なかま:いろ・かず・どうぶつ・たべもの・からだ・かぞく・あいさつ・がっこう・のりもの・てんき・いえ・うごき・きもち・ようす・スポーツ・ようび・つき・きょうか・まち・しごと)。レベル 1(ようじ〜2年)82語/〜レベル2 177語/〜レベル3 262語
- 文 30、会話 30、えほん 9、アルファベット 26
- たんご ずかん:絵・英語・意味。タップで 読み上げ、「おぼえた」チェック

## くりかえしの しくみ
- 1回目で 正解した 問題は 1・3・7・14・30日後に もう一度 出る(間隔反復)
- まちがえた 問題は「にがて」に 入り、2回 続けて 正解で 卒業。にがて復習メニューあり

## ごほうび
- ⭐:1回目の 正解で +1(えほん +3、ずかんの「おぼえた」+1)→ ランク 7段階(はじめの いっぽ〜えいご でんせつ)
- シール 24種:6割以上 正解で 1まい
- 今週の ポイントと 曜日ごとの スタンプ

## おうちの 人の 画面(かけ算の 問題で 鍵)
- 記録:今週の ポイント、正解率、学習日数、覚えた 単語、読んだ えほん、にがての 数、声に 出した 回数、クリアした ユニット、連続日数、最近14日の グラフ、メニュー別 正解率
- おこづかい:金額の 変更、今日の ポイントの 手直し(±)、6週ぶんの 達成記録
- 設定:学年、音、メニューの 音楽、自動読み上げ、英語の 速さ(3段階)、声(アメリカ/イギリス)
- きょうだい ごとの 記録、名前、記録の リセット(画面内で 確認)
- 保存:端末(localStorage)+ claude.ai アカウント(別の 端末でも 記録が 合わさる)

# 困っていること・できていない こと
1. ネイティブの 声が ない:読み上げは 端末の 機械音声。アルファベット単体の 音(フォニックス)は 不正確に なりやすい
2. 発音チェックが できない:claude.ai の ページでは マイクが 使えないので、声に 出せたかは 子どもが 自分で「いえた!」を 押す。HTML を ブラウザで 直接 開けば 音声認識が 使える 場合が ある
3. 教材が 少ない:コースは 週5日で 約18週分。えほん 9話。小6まで 続けるには 足りない。英検5級・4級に 必要な 語数・文法に 対応させたい
4. 「話せる」ように なるには、選択式の 会話だけで 足りるか 不安
5. 7歳が 毎日 自分から 開く ための しかけ(飽きさせない 工夫)を もっと 強く したい
6. 英文の チェックは AI だけ(ネイティブの 人の 確認は まだ)
7. HTML 1枚・サーバーなしの 制約の 中で できる ことに 限られる

# お願いしたい こと
次の 形で 答えてください。
1. 全体の 評価(よい 点・いちばん 大きな 問題点を それぞれ 3つまで)
2. 改善案の 一覧:表で「優先度(高・中・低)/何を 変えるか/なぜ(学習効果・継続・使いやすさの どれに 効くか)/具体的な 仕様(画面・ルール・数値)/作る 手間(小・中・大)」。まず 10個まで、優先度の 高い 順に
3. 「話せる ように する」ための 練習の 設計:マイクが 使えない 前提と、使える 前提の 両方で
4. 英検5級 → 4級 → 3級に つなげる ための 教材計画(ユニットの 足し方、文法の 順番、1週間あたりの 量)
5. 7歳が 毎日 続ける ための しかけ(ほかの 子ども向けアプリで 効果が ある とされる ものを 例に)。ただし ポイントの ルール(1日20・週100で 100円)は 変えずに
6. ネイティブ音声を 用意する 方法の 比較(録音を 依頼する、など)と 注意点

注意:
- 事実(英検の 出題範囲・語数、他社アプリの 機能や 研究結果 など)には、できるだけ 出典(URL)を つけてください。たしかでない ものは「未確認」と 書いてください
- コード全体を 書き直す 提案ではなく、上の 仕様に 足す・変える 形で 具体的に 書いてください
- 子どもの 個人情報や 声を 外部に 送る ことに なる 案には、その 注意点も 書いてください
````
