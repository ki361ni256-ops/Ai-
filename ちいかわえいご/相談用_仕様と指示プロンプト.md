## ① 相談プロンプト(Gemini・ChatGPT に 貼る)

````
あなたは、子ども向け英語教育の研究者・教材開発者・ゲームデザイナー・UXデザイナー・教育心理学の専門家を兼ねたアドバイザーです。
日本の小学生(いまは小1の娘、英語は完全な初心者)が、小1〜小6まで毎日自分から続けられ、気づいたら英語を聞いて話せるようになっている英語学習アプリを作っています。
下の「いまの仕様」と「困っていること」を読み、どこをどう改善すればよいか、具体的にアドバイスしてください。

# 目的
- 英語を好きになり、毎日自分から開く(親が毎回教えなくても一人で操作できる)
- 聞く・話す・読む・書くを段階的に育て、高学年では英検(5級→4級→3級)や中学英語につながる力をつける
- 単語暗記やポイント集めだけで終わらず、学習効果と楽しさを両立する
- 他の有名な子ども向け英語アプリのよいところを参考にし、完成度の高いアプリにしたい

# 前提・変えられない条件
- 形式:HTML 1枚のウェブアプリ(サーバーなし)。claude.ai の「アーティファクト」(非公開リンク)として公開し、タブレット・スマホ・PCのブラウザで使う
- 見た目と雰囲気は、家で使っている国語・算数アプリ「ちいかわ がくしゅうランド」とそろえる(ちいかわたちが応援する)
- ちいかわのキャラクターは家庭内で使うためだけ(販売・配布・広告はしない)
- ポイントのルール(親子で決めたもの):1日の上限20ポイント。月曜〜日曜の1週間で100ポイントたまったら、おこづかい100円(金額は親が変えられる)。途中でやめた週は0円
- 英語の音声は端末の読み上げ機能(Web Speech API の speechSynthesis)。ネイティブの録音音声はない
- claude.ai のページ内ではマイクが使えない(音声認識・録音ができない)。HTMLを直接ブラウザで開いたときだけ、音声認識が動く場合がある
- 記録は端末(localStorage)と claude.ai アカウント(アーティファクトのデータベース)の両方に保存

# いまの仕様

## ホーム画面(上から)
- なかま(ちいかわ・ハチワレ・うさぎ・モモンガ・くりまんじゅう・ラッコから選ぶ。⭐で10人増やせる)が声かけ。「なかよし レベル」(しっかり覚えた数で上がる)。「はなしかけて みる」を押すと、なかまが習った会話の質問を英語で話しかけてくる(子どもが答えてから「こたえを きく」)
- 大きな「▶ きょうの えいご」ボタン1つ:押すと次にやるミッションが自動で始まる(コース → えほん → 復習の順。2日以上休んだ日は「おかえり」と言って、短い復習から)
- 「🔤 たんご アプリ」ボタン
- 「できるように なったこと」(きょう/こんしゅう:はじめて正解・自分で言えた・忘れずに言えた・しっかり覚えた)
- 毎日1回のシールくじ、きょうのミッション3つ、ぼうけんの地図、今週のポイント(曜日ごと・おこづかいの目安・100ポイント達成が何週続いているか)
- 「ぜんぶの メニュー・えほん・おみせ」は折りたたみ
- 子どもの画面はひらがな・カタカナだけ(漢字なし)。ボタンは大きく、まちがえても責めない言葉

## 1日のミッション(3つで20ポイント)
| ミッション | ポイント |
|---|---|
| すすむコース 1ユニット(またはボス) | 10(6割以上で7、8割以上で10。同じ日にやり直して7→10に増やせる) |
| えほん 1さつ | 5(1回目で正解)/3(2回目以降) |
| すきな メニュー 1回 | 5(5割以上)/3。おすすめは「にがて → 復習の日 → じぶんで いおう」の順に自動で変わる |
- ミッション後の学習は⭐(遊び用・上限なし)だけ増える
- 別に「たんご アプリ」:20問で+3ポイント(1日2回まで)。1日の上限20は変わらない

## すすむコース(40ユニット・1日1ユニット)
- 1回で1ユニット:①まなぶ(1語ずつ絵・英語・意味。ふつうの速さ→ゆっくりの2回読み上げ。まねして言い、3秒たつと「いえた!」が押せる)→ ②クイズ(ユニットの単語+会話、約10〜13問。忘れそうな単語1問・自分で言う1問・会話2問・答えを声に出す1問を含む)。6割以上でユニットクリア
- 2回続けて6割未満だった場合は、やさしい形(聞いて選ぶ中心・3択)になる
- ユニット:あいさつ/いろ/かず/どうぶつ/たべもの/からだ/かぞく/きもち/ようす/のりもの/てんき/がっこう/うごき/スポーツ/いえのもの/ようび/大きなかず/きせつ/つき/きょうか/まち/しごと/じこしょうかい(30)+英検5級を意識した10(じかん/どこにある?(in・on・under)/できる?/いま何してる?/しつもんのことば/まいにちのこと/がっきとゲーム/おみせでちゅうもん/ふく/やすみのひ)
- 会話の例:How are you? → I'm fine, thank you. / What color do you like? → I like blue. / Can you ride a bike? → Yes, I can. / What would you like? → I'd like a hamburger, please.(40個)

## ぼうけん(8エリア・ボス)
- 5ユニットごとにエリア(はじまりの もり〜えいけん タワー)。エリアの最後にボス(でかつよ、ゴブリン など)が困りごとを抱えて待っている
- ボス戦:エリアの単語と会話から10問。7問以上で勝ち→次のエリアが開く、⭐+10

## 問題の種類(メニュー)
| メニュー | 内容 |
|---|---|
| きいて えらぼう | 英語を聞いて4つの絵から選ぶ |
| ABC と おと | 大文字→小文字/単語のはじめの文字(a apple など26文字) |
| まねして いおう | 聞いた英語を声に出して「いえた!」(自己申告) |
| じぶんで いおう | 絵や質問を見て、答えを聞く前に自分で言う→「こたえを きく」→「じぶんで いえた/まだ」(自己申告)。「まだ」は正直さをほめて、あとでまた出す |
| かいわ | 質問を聞いて答えを3択(ようじ〜2年は全選択肢に日本語訳) |
| きいて タッチ! | Touch your nose! / Point to the cat! / Where are the shoes? など英語の指示を聞いて絵を選ぶ |
| えいごで なんて いう? | 絵と日本語→英語を4択(3年〜) |
| いみ クイズ | 英単語→日本語を4択(3年〜) |
| スペル パズル | 文字を並べて単語を作る(3年〜) |
| ぶんを つくろう | 単語を並べて文を作る(3年〜) |
| きいて わかる | 英文を聞いて意味を選ぶ(3年〜) |
- 💡ヒントボタン(ゆっくり読み上げ+選択肢を2つに)。1回まちがえると自動で2択に。まちがえた問題は解説を見せて3問後にもう一度(最大2回)
- 正解:紙吹雪・効果音・なかまが喜ぶ。結果画面で「『I'm five.』を じぶんで いえたね!」のように具体的にほめる

## たんご アプリ
- 「たんご 20もん」:英語を大きく表示して読み上げ、4つの絵から選ぶ。初めての単語は「NEW!」カードで紹介し、次の単語の紹介のあとに「みて えらぶ」、最後のほうで「きいて えらぶ」でもう一度。新しい単語は1回6〜10語まで。連続正解で🔥
- 「ふりかえり テスト」:出会った単語から10問、ヒントなし(聞いて選ぶ/文字だけ読んで選ぶ 等)。結果は「おぼえて いた」「もういちど れんしゅう」に分け、メダルと記録

## えほん(9話・オリジナル)
- ちいかわ・ハチワレ・うさぎが出る短い英語のお話(Lv1:3〜4文、Lv2:5文、Lv3:5文の過去形)。単語をタップで意味と発音、1文ずつ/全部読み上げ、最後に3択クイズ

## 教材の量
- 単語326語(30のなかま)、会話40、文30、えほん9、アルファベット26、たんご図鑑(タップで読み上げ・おぼえたチェック)
- 英語はアメリカ英語でそろえている(声はアメリカ/イギリスを切り替え可能)

## 学習記録と復習(間隔反復)
- 単語・会話・文・文字の1つずつに記録:初めて/最後に出た日、正解・不正解・ヒントありの正解、答えを聞く前に自分で言えた回数、正解できた形式、強さ(0〜6)、次の復習日、しっかり覚えた日
- 復習間隔は強さで決まる(1・1・2・4・8・16・32日)。強さは1日1回まで上がり、まちがえると2下がる。まちがいが多い単語は間隔を半分に
- 復習は前回と違う形式で出す(聞いて選ぶ → 自分で言う → 意味を選ぶ など)。同じ日にすでに正解した単語は後回し
- 「しっかり覚えた」=強さ3以上+2つ以上の形式で正解+初めて正解した日から2日以上あとにも正解
- 考え方は、単語ごとに忘れる速さを見積もる研究(Settles & Meeder 2016, ACL)を簡単にしたもの

## ごほうび
- ⭐:1回目の正解で+1など → ランク7段階
- シール88種(ノーマル60・レア20・スーパーレア8):毎日1回のシールくじ(N75%/R20%/SR5%、重複は⭐+1)と、6割以上正解で1まい
- おみせ:⭐できせかえ10種(なかまの頭にのる)・新しいなかま10人・かぐ16種と交換(⭐を使ってもランクは下がらない)。「おへや」に家具を置くと、なかまたちが集まる

## おうちの人の画面(かけ算の問題で鍵)
- 4つの力(聞く・話す・読む・書く)の正答率、しっかり覚えたもの/復習が必要なもの/前はまちがえたけどできるようになったもの、おすすめ
- 学習時間(さわっている間だけ数える)、14日のグラフ、メニュー別正答率、ヒント使用数、自分で言えた回数、声に出した回数
- おこづかい(金額変更・今日のポイントの手直し・6週分の記録)、きょうのおしゃべりカード(習った会話を家で使うきっかけ)
- 設定:学年(目安)、音、メニューの音楽、自動読み上げ、英語の速さ(3段階)、声(アメリカ/イギリス・端末の声から選ぶ)、全ユニットを開く、きょうだいごとの記録、記録のひかえ(書き出し・読み込み)、エラーの記録

## 品質の確かめ方
- 教材データの自動チェック(重複・漢字・かいわの選択肢に訳があるか など)と、ブラウザで実際に操作する自動テスト47項目(本物と同じ読み取り専用データ・日本時間で、初回利用・ミッション・正誤・ヒント・保存と再起動・翌日の復習・ボス・画面幅・音が出ない端末・たんごアプリ を確認)

# 困っていること・できていないこと
1. ネイティブの声がない(端末の機械音声。アルファベット単体の音・フォニックスは不正確になりやすい)
2. 発音の判定・録音ができない(話す練習は自己申告)
3. 教材がまだ少ない:単語326語、えほん9話。小6まで、英検4級・3級までには足りない。国際的な子ども英語の基準(ケンブリッジの Pre A1 Starters など)の単語リストとまだ照合できていない
4. 読む・書くの練習が弱い(スペル・並べ替えだけで、短い文を自分で書く練習がない)
5. 高学年になっても幼く見えないデザイン・課題の変化がまだない
6. 英文の確認はAIだけ(英語の先生・ネイティブの確認はまだ)
7. 小1が毎日10〜15分で最後まで続けられる量か、まだ実際の様子で確かめていない
8. HTML 1枚・サーバーなしの制約の中でできることに限られる

# お願いしたいこと(この形で答えてください)
1. 全体の評価:よい点・いちばん大きな問題点を3つずつ
2. 改善案の一覧(最大12個、優先度の高い順):表で「優先度(高・中・低)/何を変えるか/なぜ効くか(学習効果・継続・使いやすさのどれ)/具体的な仕様(画面・ルール・数値)/作る手間(小・中・大)」
3. 「話せる」ようにする練習の設計:マイクが使えない前提で、いまの「まねして いおう」「じぶんで いおう」「かいわ」をどう発展させるか
4. 読む・書く力を育てる練習の設計(小1〜小6の段階ごと)
5. 教材を増やす計画:英検5級→4級→3級、ケンブリッジ Starters→Movers→Flyers との対応、ユニットの足し方と1週間の量
6. 7歳が毎日続けるための仕掛け(他の子ども向け英語アプリで確認できる仕組みを例に)。ただしポイントのルール(1日20・週100で100円)は変えずに
7. 高学年まで使い続けるための見た目・課題の変化のさせ方
8. ネイティブ音声を用意する方法の比較と注意点(費用・利用条件・子どものプライバシー)

注意:
- 事実(英検・ケンブリッジの出題範囲や語数、他社アプリの機能、研究結果など)には出典URLと確認日をつけ、確かでないものは「未確認」と書いてください
- コード全体を書き直す提案ではなく、上の仕様に足す・変える形で具体的に書いてください
- 子どもの個人情報や声を外部に送る案には、その注意点も書いてください
````
