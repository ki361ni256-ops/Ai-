# ちいかわ えいごランド 調査結果と改善計画(2026-10-23)

## 1. いまの アプリ(調査時点)
- 構成:HTML 1まい(`src/app.html` 画面としくみ・`src/data.js` 教材・`src/chars.js` なかまの え → `src/build.py` で `index.html`)。サーバーなし。保存は 端末(localStorage)+ claude.ai アカウント(db)
- 教材:ことば 326、ユニット 40(30+英検5級 10)、かいわ 40、ぶん 30、えほん 9、アルファベット 26
- しくみ:ミッション3つ(コース10・えほん5・すきな メニュー5=20)、週100で おこづかい、⭐・ランク、シール(くじ88種)、おみせ・おへや、にがて、間隔反復(1・3・7・14・30日、メニューごと)、じぶんで いおう、おうちの ひと画面

## 2. 強み
- まなぶ(きいて まねする)→ れんしゅう → はなそう の順で、教えてから たずねる
- まちがえても せめない。1回 まちがえると 2たくに なる。にがては 2回 つづけて せいかいで そつぎょう
- じぶんで いおう(こたえを きく まえに 思い出す)が ある
- ポイントの きまりが はっきり している

## 3. 弱み・こまる ところ
| 観点 | 問題 |
|---|---|
| 学習効果 | きろくが「メニューと ことばの くみ」ごと。同じ ことばを ちがう 形で 思い出せるか、日を あけても 思い出せるかを 見て いない。「おぼえた」の 判定が ない |
| 学習効果 | 復習は 前と おなじ 形式で でる(きいて えらぶ → また きいて えらぶ)。形を かえた 思い出しに なって いない |
| 学習効果 | ヒントを じぶんで つかう ボタンが ない。ヒントあり/なしの せいかいを 区別して いない |
| 学習効果 | 正答率が ひくい ときに やさしく する しくみが ない(学年だけで むずかしさが きまる) |
| 継続 | ホームに ボタンが おおく、1年生が「まず なにを おすか」迷う |
| 継続 | ほめ言葉が「すごーい!」など きまり文句。なにが できるように なったか 具体的に いって いない |
| 継続 | なかまが 学習で 成長しない。冒険(エリア・ボス)が なく、コースが 1本の リスト |
| 継続 | 休んだ あとの「おかえり」が ない |
| 保護者 | 4技能(きく・はなす・よむ・かく)ごとの 進み、定着した もの・復習が いる もの・できるように なった ものが 見えない。学習時間が ない |
| 技術 | 前回までに、アカウントから よんだ データが かきかえ できない ことで タップが きかなく なる 不具合が あった(2026-10-22 修正ずみ・テストに 反映ずみ) |

## 4. 今回 やる こと(優先順)
1. **ことばごとの 学習きろく**(はじめて・さいご・せいかい/まちがい・ヒント・じぶんで いえた・形式・つぎの 復習日・おぼえた 判定)と、**形式を かえた 復習**、**正答で かわる 復習間隔**
2. **ホームを「▶ きょうの えいご(つづきから)」1つで はじめられる** ように。メニューは「もっと あそぶ」に たたむ。「きょう できるように なったこと」を 上に
3. **ヒント ボタン**(💡:ゆっくり きく+2たくに)。ヒントあり せいかいは べつに きろく(子どもには 見せない)
4. **やさしく する しくみ**:コースで 2回 つづけて 6わり みまん → やさしい 形式(きいて えらぶ・3たく)で 出す
5. **具体的に ほめる**:結果画面で「きょう じぶんで いえた:I'm five.」「あたらしく おぼえた:hello」など
6. **冒険**:5ユニットごとに エリア、さいごに **ボス**(エリアの ことばを いろいろな 形で 10もん、7わりで つぎの エリアへ)。英語で こたえて ボスの こまりごとを かいけつ
7. **なかまの なかよし レベル**(おぼえた ことばで 上がる)と、**なかまが ならった 英語で はなしかけて くる**(ホームで タップ)
8. **おかえり**:2日 いじょう あいたら、みじかい 復習から
9. **おうちの ひと画面**:4技能、定着/復習が いる/できるように なった、おすすめ、学習時間
10. **自動テスト**(こおった にせ db 込み)

## 5. 今回 やらない こと(理由)
- ネイティブ音声の 録音:用意できる 音声ファイルが ない(端末の よみあげを 使う)
- 録音して 自分の 声を きく:claude.ai の ページでは マイクが つかえない
- 学年が 上がった ときの 見た目の かわりかた(おとなっぽい デザイン):次回
- 教材の 大はばな 追加(英検4級・読解):娘さんの 様子を 見てから(代表の 決定どおり)
