# 紹介文の書き方

## 共通ルール
- です・ます調。親しみやすく、押し付けない
- 1文は短め（目安60字以内）。スマホで読む前提で、こまめに改行
- 「誰に向いているか」「誰には向いていないか」を必ず書く
- 使用感は本人が書く。AIは `【要記入: 自分の使用感】` を残す
- 価格・仕様は商品ページで確認し、確認日をメモする

## 基本の型（どの媒体でも）
1. **悩みの言い当て**：「〇〇で困っていませんか？」
2. **商品の紹介**：何が・どう解決するか（商品ページの事実）
3. **使ってみて**：【要記入: 自分の使用感】
4. **合う人／合わない人**
5. **行動**：リンク・ROOM・プロフィールへ
6. **PR表記**

## 媒体別のメモ
### 楽天ROOM
- 冒頭1〜2行で目を止める（一覧では最初の数行しか見えない）
- コレクションでジャンルごとに整理する
- ハッシュタグは商品名・用途・悩みのことばで

### Threads / Instagram
- 1投稿1テーマ。リンクは貼りにくいので「プロフィールのROOMから」と誘導
- 画像（Instagram）は自分で撮ったもの・使用シーンが伝わるもの
- PR表記は本文の冒頭か、すぐ目に入る位置に

### ブログ・note
- 冒頭にPR表記
- 比較記事・まとめ記事（「〇〇の選び方と、おすすめ3選」など）が作りやすい
- リンクは本文の流れの中と、まとめの両方に置く
