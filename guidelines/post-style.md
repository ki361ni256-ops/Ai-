# 紹介文の書き方

## 共通ルール
- です・ます調。親しみやすく、押し付けない
- 1文は短め（目安60字以内）。スマホで読む前提で、こまめに改行
- 「誰に向いているか」「誰には向いていないか」を必ず書く
- 使用感は本人が書く。AIは `【要記入: 自分の使用感】` を残す
- 価格・仕様は商品ページで確認し、確認日をメモする

## 基本の型（どの媒体でも）
1. **悩みの言い当て**：「〇〇で困っていませんか？」
2. **商品の紹介**：何が・どう解決するか（商品ページの事実）
3. **使ってみて**：【要記入: 自分の使用感】
4. **合う人／合わない人**
5. **行動**：リンク・ROOM・プロフィールへ
6. **PR表記**

## 媒体別のメモ
### 楽天ROOM：悩みから書く（2026-10-03 本人方針・最優先）
- 1行目は「〇〇な人に」で始め、**誰の・どんな悩みを解決する商品か**を言う
  - ×「人気のヨガマットです」 ○「家で運動したいけど、床に膝をつくと痛い人に」
  - ×「高性能な体組成計」 ○「毎日の体重の記録が面倒で続かない人に」
- 2行目以降で、その悩みをどう解決するか（商品の特徴・レビューで多かった声）
- 商品は `02_plan/nayami-list.md` の悩みから選ぶ。持っていない商品はレビュー要約で書き、使ったようには書かない

### 楽天ROOM：伸びている人の紹介文の型（2026-10-03 本人が見つけた例より）
1. **自分のタグ**（例 `#タクロウ🦉ボディバッグ`）を1行目に → 同じタグの投稿がまとめて見られる「自分だけの棚」になる
2. **場面のひとこと**（子連れの長距離ドライブ、公園遊び、雨の日 など）＋ **悩みの問いかけ**（「〜しませんか😣」）。月・季節・行事・連休の言葉は入れない（2026-10-04 本人判断：「10月の〜」は翌月に古く見えるため）
3. **「〇〇が解決✨」**：商品名で答える
4. **場面とセットで特徴**（「抱っこしても、走っても邪魔にならない」）
5. **使う場面・合わせ方**（服なら「パーカー×デニムの公園あそびに」）、色やサイズの選択肢
6. **自分のタグで他の商品へ案内**（「#タクロウ🦉ボディバッグ で他のバッグもまとめてます」）
7. **「🔻楽天市場で見てみる🔻」** で締め、ハッシュタグ（商品・種類・場面・自分のタグ）
- 絵文字入りのタグ（`#タクロウ🦉バッグ`）でもROOMのタグ検索で表示される。ただし投稿・編集してから検索に出るまで少し時間がかかる（2026-10-04 確認）
- 使っていない商品でも書ける言い方にする（「解決」「〜しやすい」「〜できる」は商品の特徴として書く。「使ってよかった」とは書かない）
- 月・季節・行事・連休の言葉は書き出しに入れない。いつ読んでも通じる「場面」で書く

### 楽天ROOM
- 型（2026-10-02 本人が参考にした人気ROOMの紹介文から）:
  - 1行目は【】や絵文字で囲んだキャッチ（商品の一番の特徴）
  - 2〜4行で特徴（素材・デザイン・使う場面）。「〜で可愛い」「〜しやすそう」など、使っていなくても言える言い方
  - 絵文字を多め（行ごとに1〜2個）
  - ハッシュタグは8〜10個（ブランド名・品名・素材・テイスト・季節・使う場面）
  - 価格・割引率・送料は書かない（すぐ変わるため）
- 冒頭1〜2行で目を止める（一覧では最初の数行しか見えない）
- コレクションでジャンルごとに整理する
- ハッシュタグは商品名・用途・悩みのことばで

### 楽天ROOM：人気ROOMから学んだこと（2026-10-03 本人が見つけた例より）
- **自分で撮った写真（#オリジナル写真）** を使うと目立つ。ROOM には「#オリジナル写真」で絞り込む機能もある
  - 写真に「Type-C」「LEDライト」のような書き込みや、特徴の箇条書きを入れると、一覧で目に止まりやすい（iPhone の写真アプリの「マークアップ」や、文字入れアプリで作れる）
  - **使えるのは、自分が持っている商品を自分で撮った写真だけ**。ショップの商品画像を加工して「オリジナル写真」として載せない（ショップの画像の無断加工・転載になるおそれ）
- 写真の中に「スペックの箇条書き」、本文に「使う場面（旅行・防災・運動会…）」を並べると、誰向けか伝わりやすい
- セール中は、そのセールのタグ（#お買い物マラソン #楽天スーパーSALE）を付ける。**実際に開催中のときだけ**
- まねしないこと
  - 「最安」「楽天1位〇冠」「人気No.1」：確認できないことは書かない（ショップ表記の受け売りでも、時間がたつと事実でなくなる）
  - 価格・クーポン：すぐ変わる
  - 商品と関係ないタグを大量に付ける（例：充電器に #Switch2 #新生活 #運動会 をまとめて付ける）

### Threads / Instagram
- 1投稿1テーマ。リンクは貼りにくいので「プロフィールのROOMから」と誘導
- 画像（Instagram）は自分で撮ったもの・使用シーンが伝わるもの
- PR表記は本文の冒頭か、すぐ目に入る位置に

### ブログ・note
- 冒頭にPR表記
- 比較記事・まとめ記事（「〇〇の選び方と、おすすめ3選」など）が作りやすい
- リンクは本文の流れの中と、まとめの両方に置く

## 自分で書くときの穴埋めテンプレ

### 使っているもの
```
（どんな場面で困っていたか）なので、
（商品名）を使っています。
（よかったところ・ひとこと）。
（気になるところ・正直にひとこと）。

▼合う人
・
▼合わない人
・

※楽天アフィリエイトを利用しています
```

### 欲しいもの
```
【欲しいものリスト】
（何のために）気になっている（商品名）です。
（気になっている理由）。
（迷っている理由：値段・大きさなど）。

▼合う人
・
▼合わない人
・

※楽天アフィリエイトを利用しています
```

### コツ
- 商品のスペックより「自分の場面」を書く（例: 「重い」より「スーパーから持ち帰るのが大変」）
- 気になるところも1つ書くと、売り込み感が減る
- 欲しいものは「使ってみた」「おすすめです」と書かず、「気になっている」「迷い中」と書く
