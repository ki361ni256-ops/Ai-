# 紹介文の書き方

## 共通ルール
- です・ます調。親しみやすく、押し付けない
- 1文は短め（目安60字以内）。スマホで読む前提で、こまめに改行
- 「誰に向いているか」「誰には向いていないか」を必ず書く
- 使用感は本人が書く。AIは `【要記入: 自分の使用感】` を残す
- 価格・仕様は商品ページで確認し、確認日をメモする

## 基本の型（どの媒体でも）
1. **悩みの言い当て**：「〇〇で困っていませんか？」
2. **商品の紹介**：何が・どう解決するか（商品ページの事実）
3. **使ってみて**：【要記入: 自分の使用感】
4. **合う人／合わない人**
5. **行動**：リンク・ROOM・プロフィールへ
6. **PR表記**

## 媒体別のメモ
### 楽天ROOM
- 型（2026-10-02 本人が参考にした人気ROOMの紹介文から）:
  - 1行目は【】や絵文字で囲んだキャッチ（商品の一番の特徴）
  - 2〜4行で特徴（素材・デザイン・使う場面）。「〜で可愛い」「〜しやすそう」など、使っていなくても言える言い方
  - 絵文字を多め（行ごとに1〜2個）
  - ハッシュタグは8〜10個（ブランド名・品名・素材・テイスト・季節・使う場面）
  - 価格・割引率・送料は書かない（すぐ変わるため）
- 冒頭1〜2行で目を止める（一覧では最初の数行しか見えない）
- コレクションでジャンルごとに整理する
- ハッシュタグは商品名・用途・悩みのことばで

### Threads / Instagram
- 1投稿1テーマ。リンクは貼りにくいので「プロフィールのROOMから」と誘導
- 画像（Instagram）は自分で撮ったもの・使用シーンが伝わるもの
- PR表記は本文の冒頭か、すぐ目に入る位置に

### ブログ・note
- 冒頭にPR表記
- 比較記事・まとめ記事（「〇〇の選び方と、おすすめ3選」など）が作りやすい
- リンクは本文の流れの中と、まとめの両方に置く

## 自分で書くときの穴埋めテンプレ

### 使っているもの
```
（どんな場面で困っていたか）なので、
（商品名）を使っています。
（よかったところ・ひとこと）。
（気になるところ・正直にひとこと）。

▼合う人
・
▼合わない人
・

※楽天アフィリエイトを利用しています
```

### 欲しいもの
```
【欲しいものリスト】
（何のために）気になっている（商品名）です。
（気になっている理由）。
（迷っている理由：値段・大きさなど）。

▼合う人
・
▼合わない人
・

※楽天アフィリエイトを利用しています
```

### コツ
- 商品のスペックより「自分の場面」を書く（例: 「重い」より「スーパーから持ち帰るのが大変」）
- 気になるところも1つ書くと、売り込み感が減る
- 欲しいものは「使ってみた」「おすすめです」と書かず、「気になっている」「迷い中」と書く
