# 楽天ROOM用 AIプロンプト（Gemini・ChatGPT用・悩み起点）

2026-10-03 本人方針「誰のどんな悩みを解決するか」で商品を選ぶ、をAIに手伝ってもらうためのプロンプト。
2つを順番に使う。iPhone のユーザー辞書には1行版を登録する（よみの例：なやみ／るーむ）。

1. **なやみ**: 悩み → 楽天で探すキーワードと選び方を出してもらう（悩みが空なら、悩みの候補を出してもらう）
2. **るーむ**: 選んだ商品のレビューを貼る → 紹介文とハッシュタグを出してもらう

悩みと載せた商品は `02_plan/nayami-list.md` に記録する（Claude に「載せた：〇〇」と言えば記録する）。

## 2. るーむ（紹介文づくり）

### 1行版
```
楽天ROOMの紹介文を作ります。最後に貼る「悩み」「商品名」「レビュー」をもとに、紹介文を1つだけ出力してください（前置き・説明・複数案なし）。【書き方】1行目は絵文字ではさんだ「〇〇な人に」で始め、誰のどんな悩みを解決する商品かを言う／2〜5行目で、その悩みをどう解決するかを商品の特徴とレビューで多かった声で書く（「レビューでは〜という声が多い」）／レビューに出ている気になる点があれば1つだけ正直に入れる／1行ごとに絵文字を1〜2個／全体で6行以内／最後に改行して、商品名・種類・悩み・使う場面のハッシュタグを8〜10個。【守ること】私はこの商品を使っていないので、使った感想として書かない（「使ってみた」「買ってよかった」「わが家では」は使わない）／レビューの文章をそのまま写さず自分の言葉で要約する／価格・クーポン・送料・「最安」「1位」「No.1」は書かない／効果効能（痩せる・治る・疲れがとれる・よく眠れる・肌がきれいになる等）は、レビューに書いてあっても書かない／関係ないハッシュタグは付けない。悩み・商品名・レビュー：
```

### 改行版
```
楽天ROOMの紹介文を作ります。最後に貼る「悩み」「商品名」「レビュー」をもとに、紹介文を1つだけ出力してください（前置き・説明・複数案なし）。

【書き方】
・1行目は絵文字ではさんだ「〇〇な人に」で始め、誰のどんな悩みを解決する商品かを言う
・2〜5行目で、その悩みをどう解決するかを、商品の特徴とレビューで多かった声で書く（「レビューでは〜という声が多い」）
・レビューに出ている気になる点があれば、1つだけ正直に入れる
・1行ごとに絵文字を1〜2個。全体で6行以内
・最後に改行して、商品名・種類・悩み・使う場面のハッシュタグを8〜10個

【守ること】
・私はこの商品を使っていないので、使った感想として書かない（「使ってみた」「買ってよかった」「わが家では」は使わない）
・レビューの文章をそのまま写さず、自分の言葉で要約する
・価格・クーポン・送料・「最安」「1位」「No.1」は書かない
・効果効能（痩せる・治る・疲れがとれる・よく眠れる・肌がきれいになる 等）は、レビューに書いてあっても書かない
・関係ないハッシュタグは付けない

悩み・商品名・レビュー：
```

### 貼るときの形（例）
```
悩み：夜泣きで親が眠れない
商品名：〇〇（楽天の商品名をそのまま）
レビュー：
（レビューを3〜5件、★の低いものも1件入れる）
```

## 持っている商品のとき
「私はこの商品を使っていないので〜」の行を「私はこの商品を使っている。使った感想は次の内容だけ使う：〇〇」に書きかえる。感想は本人の言葉だけ。
