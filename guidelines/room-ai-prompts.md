# 楽天ROOM用 AIプロンプト（Gemini・ChatGPT用・悩み起点）

2026-10-03 本人方針「誰のどんな悩みを解決するか」で商品を選ぶ、をAIに手伝ってもらうためのプロンプト。
**いちばん楽なのは「0. いっき」**（テーマを書くだけで5品ぶんの投稿ができる）。じっくり選びたいときは1と2を順番に使う。iPhone のユーザー辞書には1行版を登録する（よみの例：なやみ／るーむ）。

1. **なやみ**: テーマ → 悩み・解決商品・楽天リンク・選ぶポイントを5組まとめて出してもらう
2. **るーむ**: 選んだ商品のレビューを貼る → 紹介文とハッシュタグを出してもらう

悩みと載せた商品は `02_plan/nayami-list.md` に記録する（Claude に「載せた：〇〇」と言えば記録する）。

**【紹介済み】の更新**: 「なやみ」には紹介済みの商品の一覧が入っている（Gemini・ChatGPTは前の会話を覚えていないため）。商品を載せたら、Claude に「載せた：〇〇」と送る → `nayami-list.md` とこのファイルの【紹介済み】を更新し、新しい1行版を返すので、ユーザー辞書を入れ替える。急ぐときは、プロンプトの最後の「悩み：」の前に「、〇〇」と書き足してもよい。

## 0. いっき（テーマを書くだけで、5品ぶんの投稿をまとめて作る）★いちばん楽

「なやみ」→リンクを開く→レビューをコピー→「るーむ」の工程を、1回にまとめた版。Gemini（ネット検索ができる）で使う。

### 使い方（3ステップ）
1. Gemini で「いっき」を呼び出し、最後に `テーマ：パパのバッグ　時期：来週の3連休` のように書いて送る（時期は空欄でもよい）
2. 出てきた **「ROOMで検索する商品名」** を ROOM の投稿画面の検索に貼る
   - **見つからなければ、その商品は飛ばす**（AIが間違えた可能性がある。ROOMの検索がそのまま確認になる）
   - 見つかったら、ショップ名がだいたい合っているものを選ぶ
3. **「紹介文」** を貼って投稿 → コレクションに入れる

5品で15〜20分が目安。投稿したら、まとめて Claude に「載せた：〇〇、〇〇…」と送る（紹介済みの一覧を更新して返す）。


## 2. るーむ（紹介文づくり・人気ROOMの型）

2026-10-03 本人が見つけた人気ROOMの紹介文の型（自分のタグ・時期のひとこと・悩みの問いかけ・「〇〇が解決」・場面・他の商品への案内）を入れた版。

### 1行版
```
楽天ROOMの紹介文を作ります。最後に貼る「タグ」「時期」「悩み」「商品名」「レビュー」をもとに、紹介文を1つだけ出力してください（前置き・説明・複数案なし）。【構成】①1行目に「タグ」をそのまま書く②時期が書いてあれば時期のひとことを入れ、悩みを問いかけで書く（「〜しませんか😣」）③「（商品名を短く）が解決✨」④その悩みをどう解決するかを、使う場面とセットで2〜3行（商品の特徴とレビューで多かった声。「レビューでは〜という声も」）⑤使う場面や合わせ方を1〜2行、色やサイズの選択肢があれば1行⑥「（タグ）で他の商品もまとめてます」⑦「🔻楽天市場で見てみる🔻」⑧改行して、商品名・種類・悩み・使う場面のハッシュタグを6〜8個と、最後に「タグ」と「#タクロウおすすめ」。【書き方】1行ごとに絵文字1〜2個、短い行で改行、全体で15行以内。【守ること】私はこの商品を使っていないので、使った感想として書かない（「使ってみた」「買ってよかった」「わが家では」は使わない）／レビューの文章をそのまま写さない／時期・行事は私が書いたときだけ入れる／価格・クーポン・送料・「最安」「1位」「No.1」は書かない／効果効能（痩せる・治る・疲れがとれる・よく眠れる・肌がきれいになる等）は書かない／関係ないハッシュタグは付けない。タグ・時期・悩み・商品名・レビュー：
```

### 貼るときの形（例）
```
タグ：#タクロウ🦉ボディバッグ
時期：来週の3連休（なければ空欄）
悩み：子どもを抱っこするとバッグがずり落ちる
商品名：（楽天の商品名をそのまま）
レビュー：
（3〜5件。★の低いものも1件）
```

### 自分のタグ（コレクションごとに1つ）
- `#タクロウ🦉子育てグッズ` `#タクロウ🦉時短家事` `#タクロウ🦉パパのガジェット` `#タクロウ🦉おでかけ`
- カバン特集を作るなら `#タクロウ🦉ボディバッグ` `#タクロウ🦉マザーズバッグ` `#タクロウ🦉ビジネスバッグ` のように種類ごと
- 同じタグを付けた投稿は、ROOMでタグを押すとまとめて見られる

## 持っている商品のとき
「私はこの商品を使っていないので〜」の行を「私はこの商品を使っている。使った感想は次の内容だけ使う：〇〇」に書きかえる。感想は本人の言葉だけ。
