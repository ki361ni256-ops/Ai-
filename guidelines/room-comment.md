# 楽天ROOM コメントの仕組み（2026-10-06）

人気ROOMは、いいね・コメントを「人と人のやり取り」で集めている（本人の観察：1商品にコメント600・いいね2000）。
毎回自分で文を考えるのは大変なので、**文はGeminiに作らせ、送るのは自分**にする。

## やってはいけないこと（ROOMの規約・アカウント制限のリスク）
- 自動でいいね・コメントするツールやボットを使わない（全部手で送る）
- 同じ文を何人にもコピペしない
- 短時間に大量のいいね・コメントをしない（制限がかかることがある）
- コメントで自分のROOMや商品へ誘導しない

## 1日15分のルーティン
1. 自分の投稿についたコメントに全部返信する（プロンプト②）
2. コメントやいいねをくれた人のROOMに行き、1つコメントといいね（お返し）
3. 同じジャンル（子育て・家事・パパ）の人の新しい投稿に、3〜5件コメント（プロンプト①）
4. いいねは20件くらいまで

相手の投稿のスクショか紹介文を一緒に貼って送る。
