# 都市伝説チャンネル 制作体制

都市伝説系 YouTube 動画（ショート中心・長尺も可）を、役割を分けた AI 社員で作る。

## AI社員（.claude/agents/）
| 担当 | ファイル | 作るもの |
|---|---|---|
| 企画 | densetsu-planner | 01_企画.md（切り口・フック・タイトル案・被り確認） |
| リサーチ | densetsu-researcher | 02_リサーチ.md（事実／噂／創作・不明 を出典つきで分類） |
| 構成・台本 | densetsu-writer | 03_台本.md（秒数・ナレーション・テロップ・画面メモ） |
| 演出 | densetsu-director | 04_演出.md（カット指示・BGM・素材とライセンス・画像プロンプト・サムネ案） |
| チェック | densetsu-checker | 05_チェック.md（事実と噂・名誉毀損・著作権・YouTube開示・品質採点） |
| 編集長 | densetsu-editor | 06_編集長判断.md（GO/修正/ボツ・タイトル決定・概要欄・学び） |

```
テーマ → 企画 → リサーチ → 台本 → 演出 → チェック ─┬→ 編集長 GO → 本人が制作・公開
                                         └→ 要修正：該当担当がやり直し（最大2周）
```

## 使い方
Claude に「〇〇の都市伝説でショート作って」「ネタ出しして」と頼むと、`.claude/skills/densetsu-douga` の流れで全員が順に動く。成果物は `作品/<日付>_<slug>/` に残る。

## チャンネルの決まり
1. **事実と噂を言い分ける**。噂は「〜と言われている」「〜という説がある」で語る
2. 実在の個人・企業を根拠なく悪く言わない。事件・災害の被害者をネタにしない
3. 医療・健康・選挙・災害など、信じると実害が出る説は肯定しない（検証・否定の切り口でだけ扱う）
4. 他人の映像・音楽・画像・文章を無断で使わない。素材はライセンスを記録する
5. 本物らしく見える生成・合成映像を使うときは、YouTube の「改変・合成コンテンツ」の開示が必要か確認する
6. 毎回同じ型・同じ言い回しの量産にしない（独自の考察・編集を入れる）
7. 公開は本人が行う。再生数や収益を約束しない

※ 5・6 は YouTube のポリシーに関わるため、公開前に最新の公式ヘルプで確認すること（ポリシーは変わる）。

## ファイル
- `品質基準.md` … チェック担当が使う採点表
- `ネタ帳.md` … テーマ候補・使用済みテーマ・回ごとの学び
- `作品/` … 回ごとの成果物
