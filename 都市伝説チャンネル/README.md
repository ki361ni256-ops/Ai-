# 都市伝説チャンネル 制作体制

都市伝説系 YouTube 動画を、役割を分けた AI 社員で作る。

**基本の形：1テーマ＝長尺（10分以上）＋その要点をまとめたショート（約1分）のセット**。ショートで知ってもらい、本編で深く見てもらう。

**チャンネルの型：「聞かせる」チャンネル（2026-10-10 本人方針）**。映像で見せるのではなく、ナレーション（本人の声）で聞かせる。画面を見ていなくても、耳だけで話が分かることを最優先にする。
- 台本：画面に頼る言い方（「画面の札」「ご覧の図」「左の表」など）を使わない。数字・固有名詞・年は耳で聞いて分かるように言う。章の頭で「ここからは〜」と区切りを言葉で示す
- 画面：作り込んだカットではなく、雰囲気の背景イラスト＋章タイトル＋字幕（ナレーションの文字）を基本にする。作業を軽くし、声に集中してもらう
- 収録：本人が収録台本（ふりがな付き）を読む。録音は `素材/tools/narrate.py` で台本の行に当てはめ、言い直しは自動で削る

## いちばん大事なこと（代表方針 2026-10-11）
**あふれる動画の中から選んでくれた視聴者・気に入ってくれた視聴者を大事にする。** そのために、楽しんでもらえる動画を作り、専門の検品を通してから納品する。代表の指示と起きたミスは `代表の指示.md` に記録する。

## 体制
- **代表**：本人。方針を決め、ナレーションを録り、公開ボタンを押す
- **ナンバー2（監査役）**：densetsu-auditor。チーム全体と全工程を監査し、代表に報告する
- **マネージャー**：densetsu-manager。進行表・公開予定・代表の作業をまとめ、各担当に割り振る

| 担当 | ファイル | 作るもの |
|---|---|---|
| 企画 | densetsu-planner | 01_企画.md（切り口・フック・タイトル案・被り確認） |
| リサーチ | densetsu-researcher | 02_リサーチ.md（事実／噂／創作・不明 を出典つきで分類） |
| 構成・台本 | densetsu-writer | 03_台本_長尺.md（10分以上・章立て）／03_台本_ショート.md（約1分）。耳だけで分かる台本 |
| 演出 | densetsu-director | 04_演出.md（背景・章名・字幕を中心にした画面、図解は必要な所だけ） |
| チェック | densetsu-checker | 05_チェック.md（事実と噂・名誉毀損・著作権・YouTube開示・品質採点） |
| 編集長 | densetsu-editor | 06_編集長判断.md（GO/修正/ボツ・タイトル決定・概要欄・学び） |
| 検品（完成動画の最終チェック専門） | densetsu-qa | 07_検品.md（完成動画の画面と音を実物で確かめ、納品OK／差し戻し） |
| ナンバー2（監査） | densetsu-auditor | 08_監査.md（工程・決まり・代表の指示・視聴者目線を監査し、代表に報告） |

```
企画 → リサーチ → 台本 → 演出 → チェック → 編集長 → 代表が収録 → 書き出し → 検品 → 監査 → 代表へ納品 → 代表が公開
                                         └→ 要修正：該当担当がやり直し          └→ 差し戻し：該当担当が直し、検品からやり直し
```
マネージャーが全体の進行を管理する（`進行表.md`）。

## 使い方
Claude に「〇〇の都市伝説で動画作って」「ネタ出しして」と頼むと、`.claude/skills/densetsu-douga` の流れで全員が順に動く。成果物は `作品/<日付>_<slug>/` に残る。

## チャンネルの決まり
1. **事実と噂を言い分ける**。噂は「〜と言われている」「〜という説がある」で語る
2. 実在の個人・企業を根拠なく悪く言わない。事件・災害の被害者をネタにしない
3. 医療・健康・選挙・災害など、信じると実害が出る説は肯定しない（検証・否定の切り口でだけ扱う）
4. 他人の映像・音楽・画像・文章を無断で使わない。素材はライセンスを記録する
5. 本物らしく見える生成・合成映像を使うときは、YouTube の「改変・合成コンテンツ」の開示が必要か確認する
6. 毎回同じ型・同じ言い回しの量産にしない（独自の考察・編集を入れる）
7. 公開は本人が行う。再生数や収益を約束しない

※ 5・6 は YouTube のポリシーに関わるため、公開前に最新の公式ヘルプで確認すること（ポリシーは変わる）。

## ファイル
- `品質基準.md` … チェック担当が使う採点表
- `ネタ帳.md` … テーマ候補・使用済みテーマ・回ごとの学び
- `収益化プラン.md` … 月3万円を目標にした収入源・制作ペース・毎月の振り返り表（目標であって保証ではない）
- `作品/` … 回ごとの成果物
