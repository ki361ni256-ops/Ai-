## 作り直し方
```
sh ../../../素材/fonts/fetch.sh   # 初回だけ（フォント取得）
node build.mjs                     # 画像をすべて書き出す（約1分半）
python3 make_video.py              # 下書き動画を作る（約2分）
ffmpeg -y -pattern_type glob -i 'long/*.png' -vf "scale=320:180,tile=8x14:padding=4:color=white" -q:v 4 一覧_長尺.jpg
```
- この回専用の部品（年表バー `nenpyo`、木箱 `box`、札 `fuda`、記録カード `rec`、影絵 `scenes` など）は build.mjs の中にある。共通ツール（`素材/tools/`）は import しているだけで変更していない
- make_video.py は 04_演出.md の表を直接読む。演出の行を足し引きしたら番号がずれるので、build.mjs の番号も合わせて直す
