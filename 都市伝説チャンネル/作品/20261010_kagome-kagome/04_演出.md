# 04 演出：かごめかごめ

- 作成：演出担当（densetsu-director）／2026-10-10（同日、`05_チェック.md` の指摘を反映し、さらに台本修正版に合わせ込み。末尾の修正履歴を参照）
- 元にした資料：`01_企画.md`、`02_リサーチ.md`、`03_台本_長尺.md`（修正版）、`03_台本_ショート.md`（修正版）、`05_チェック.md`
- 形式：長尺（横16:9・約13分20秒）＋ショート（縦9:16・約60秒）
- テロップ文言・秒数・チャプターは、台本修正版（長尺・ショート）に合わせてある。今後台本が変わったら、こちらも同時に直す
- **演出の軸は2つだけ**
  1. **画面下の年表バー**：最初は空。章が進むたびに項目が書き込まれ、最後に「左端の空白」が残る。**左端側＝記録**（図書館の回答・幻燈原板・野田市資料・『こども風土記』）、**右端側＝説**（1998・1999・2007年の札）と図書館の質問（2008〜2022年）
  2. **「初出不明」の箱**：年表の外（長尺は画面右下）に置く木箱。日付がたどれない説の札が、ここに入っていく
  - 冒頭からラストまで、この2つが画面のどこかに必ず見えている状態にする（第1章などで主役でないときも、画面下に小さく残す）
- 注意：台本は「公開前に本人がブラウザで原文確認すべき箇所」が多い。確認の結果で台本の行が削られたり数が変わったら、**年表に置く項目・札の数・テロップ・「本文未確認」の小札・サムネの文字も同時に直す**こと（特に「2つ」）。原文で確認できた項目は「本文未確認」の小札を外してよい

### 「2つ」の数え方（この作品の決まり）

- 年表に置く柿色の札は **3枚（1998年・1999年・2007年）**、数える**説は2つ**
  - 1998年と2007年は同じ著者による同じ系統の解釈なので、**説としては1つ**に数える（台本 7:03 のナレーションで説明）
  - 画面では、2007年の札を1998年の札の**すぐ右に寄せ、細い線と1つの枠（柿色の囲み）でつなぐ**
- 「2つ」は WebSearch の抜粋という限られた調べ方で見つかった数。**「2」を出すときは必ず「今回の調べで」の限定を一緒に出す**（下の 1-1 の数字ルール。台本のテロップにも入っている）

## 0. 全体で守ること（この作品の個別ルール）

| 項目 | ルール |
|---|---|
| 子ども | 実写の子どもは使わない。生成画像は**影絵（シルエット）・切り絵調だけ**。顔・目鼻を描かない。実在の子どもに似せない（特定の子の写真を元に生成しない、名前や顔写真をプロンプトに入れない） |
| 寺社 | 籠神社・伊勢神宮・日光東照宮は**文字カードのみ**。写真・イラスト・鳥居や社殿のシルエットも出さない。不気味な加工（揺れ・ノイズ・赤い光・低音の効果音）を重ねない。寺社の見解は「今回は調べていない」と出す（7:33・8:19）。「確認できなかった」「公式な説明はない」とは書かない |
| 流産説の区間（長尺 6:17〜7:03、ショート 0:25〜0:36） | 暗い演出をしない。画面は明るめの生成り色、BGMは薄く温かいものに。効果音なし。札の揺れ・光り・ズームなし。読み方（「籠女」など）の文字は出さない |
| 実在の人物 | 山中直治・柳田国男・関裕二・久野俊彦などは**名前の文字カードだけ**。写真・肖像画・生成した顔は使わない |
| 書籍・データベース | 表紙・本文・図書館データベースや日文研データベースの画面キャプチャは**使わない**。書名・事例名・出典は文字で再構成する（使いたくなった場合は「10. 確認事項」へ） |
| 新聞 | 朝日新聞の紙面・ロゴは使わない。「朝日新聞の連載（1941年）」という文字カードのみ |
| ネット記事 | 実在サイトのスクリーンショットは使わない。0:50 の「まとめ記事風」は、架空の画面を自作してぼかす（実在サイトのロゴ・配色をまねない） |
| 旋律 | **既定は案B（かごめかごめの旋律を使わない。オリジナルのオルゴール単音モチーフ）**。案A（自前演奏の旋律）は、本人が権利を確認した場合だけの選択肢（「6-1」）。逆再生の音は流さない |
| 残酷な描写 | 遊女・囚人・処刑・出産に関わる人物や場面の絵は描かない。説の名前を札の文字で出すだけ |
| 地図 | 日本地図のシルエットは自作。締め（12:18〜）とショート 0:51 は**県境のみ・印なし**（特定の場所を指さない） |

## 1. チャンネル共通：テロップと画面の強調ルール

同日制作のきさらぎ駅・八尺様と共通で使えるよう、**チャンネル共通ルール**として書く（他2作の演出担当にも同じルールを申し送る）。

### 1-1. テロップの色と意味（毎回同じ）

| 種類 | 見た目 | 使う場面 |
|---|---|---|

| 噂・説 | 文字の下に**柿色（#C8743A）の下線**。末尾に「〜という説」「〜と言われています」を必ず入れる | 怖い説・謎の説すべて |
| 本文未確認（出典はあるが本文を開けていない） | カード・札の右下の隅に付ける**小さな灰色の札（#7A7A7A 地・白文字「本文未確認」）**。テロップではなく部品として常に付けたままにする | 1:57 の記録カード、3:03 以降の本文未確認の出典による項目すべて（5:48 で一斉に一瞬光る） |

| 学説（怖い噂ではない説明） | **藍色（#2F4A6D）**の下線・札 | 神寄せ・地蔵遊び起源（10:06〜10:33） |
| 問いかけ・フック | 画面中央に大きく。白（暗背景）／墨（明背景） | 0:00、5:19、9:02、12:18 など |
| 数字の強調 | 黄色（#E9C46A）で大きく。**調べた範囲に限られる数字には、同じテロップの中に「今回の調べで」「少なくとも」などの限定を必ず入れる**（数字だけを単独で出さない） | 5:32 の「2」、9:25 の「4件」 |

### 1-2. 出し方

- 出る：0.2〜0.3秒のフェード（または左から右へ短いワイプ）。ポップ・弾む動きは使わない
- 消える：0.2秒のフェード
- 揺れ・ノイズ（グリッチ）は「宙に浮いた説の札」の演出だけに限定。**寺社名・流産説・遊女説・囚人説のテロップと札には使わない**
- 1画面のテロップは2行まで。長い出典は2枚に分ける
- 「〇〇≠〇〇」の形のテロップは使わない（文で言い切る）
- 長尺：年表バーが画面下（下から0〜11%）にあるので、テロップは**下から13〜28%の帯**に出す。出典表示は年表バーのすぐ上の左端
- ショート：上下の UI に隠れないよう、テロップは**画面の上から20〜65%**に収める（目安。下20%・右端15%は避ける）

### 1-3. 年表と札の色（画面の部品）

| 部品 | 見た目 |
|---|---|
| 年表バー | 1本の細い線＋目盛り。暗背景では生成り色、明背景では墨色。左端「江戸」、右端「現在」 |
| 記録カード（史料・図書館回答・事典・書誌） | 生成り地（#F1E9DA）・墨文字・細い墨枠の長方形 |
| 説の札（怖い説・謎の説） | 柿色（#C8743A）地・白文字の荷札形。**赤（血の色）は使わない** |
| 同じ系統の札のまとまり | 柿色の細い囲み線で複数の札を1つに囲む（この作品では 1998・2007） |
| 学説の札 | 藍色（#2F4A6D）地・白文字。年表の上ではなく、**年表の下の別の段**に置く（怖い説の札と並べない） |
| 「本文未確認」の小札 | 灰色地・白文字の小さな札。カード・札の右下隅に重ねる（文字の高さはカードの文字の半分程度） |
| 未確認の付せん | 黄色（#E9C46A） |
| 「初出不明」の箱 | 素朴な木箱（生成画像 P05 を切り抜き）。ふたに墨文字で「初出不明」（文字は編集ソフトで載せる） |
| 作者欄 | 年表の左端に、記録カードと同じ見た目で「作者：　　」（空白）。最後まで空白のまま |

### 1-4. 全体の色味

- オープニング・ラスト：墨黒（#141414）の背景に生成り色の線
- 本編（調べもの・記録の場面）：生成り色の和紙調背景。明るめ
- 影絵の場面：夕暮れの橙〜薄紫のグラデーション（くすませる。ホラー調の青緑・赤は使わない）
- 流産説の区間：本編よりさらに少し明るい生成り

### 1-5. 回ごとに変えるもの（量産に見せないため）

- 終盤の振り返りは「分かったこと／分からないこと」の左右2列の表にしない。この回は**年表と箱そのものの上で整理する**（左端側＝記録、右端側＝説、箱＝初出不明。カメラが左端→右端→箱→左端と動く）
- 最後の問いかけは、その回の題材にしかない問いを主役にする（この回は「あなたの地域の歌詞」）。「初めて聞いたのはいつ？」型は他の回と重なるので使わない
- サムネは「数字を大きく見せる」型を続けて使わない

## 6. BGM・効果音

### 6-1. かごめかごめの旋律について（必ず読む）

- **既定は案B（旋律を使わない）**。理由（`05_チェック.md` 修正点4）：
  - 伝統的な歌詞・旋律がパブリックドメインだと公的機関が明言した資料は見つかっていない（`02_リサーチ.md` 6章）。作者不明の伝承で、採譜した山中直治も1937年に亡くなっているので、権利が残っている可能性は低いと見込まれるが、**確定はしていない（未確認。著作権法の条文も未確認）**
  - 自前で演奏しても、既存の録音と照らし合わされて自動で権利の申し立てを受ける心配がある（一般論としての懸念。この作品で実際に起きるかは未確認）
  - 使うのは1小節と最後の1音だけなので、旋律がなくても作品の価値はほとんど落ちない
- 既存の音源・既存の編曲譜・他人の演奏動画からの抜き出しは、案A・案Bどちらでも**使わない**（市販CD・配信音源には著作隣接権、現代の出版楽譜の編曲部分にも権利がありうる）

| 案 | 中身 | 条件 |
|---|---|---|
| **案B（既定）** | かごめかごめの旋律もハミングも使わない。**オリジナルのオルゴール単音モチーフ**（かごめの旋律に似せない3〜4音。0:00 で鳴らし、13:07 とショート 0:51 でその最後の1音だけ鳴らす）＋夕暮れの環境音（風・遠い虫の声）＋低いパッドで構成する | 条件なし |

## 9. 「改変・合成コンテンツ」の開示について

- **この演出プランどおり（影絵・切り絵調・平面イラスト・図解・文字カードのみ）なら、開示は原則不要の見込み**。明らかにイラスト・アニメーションと分かる表現で、実在の人物・場所・出来事を本物のように見せるものではないため（チェック担当の確認では、YouTube はアニメーションや明らかに現実ではない内容を開示の対象外にしていると報じられている。2024年3月の発表の報道。`05_チェック.md` 参照）
