# 04 演出：かごめかごめ

- 作成：演出担当（densetsu-director）／2026-10-10
- 元にした資料：`01_企画.md`、`02_リサーチ.md`、`03_台本_長尺.md`、`03_台本_ショート.md`
- 形式：長尺（横16:9・約13分）＋ショート（縦9:16・約60秒）
- **演出の軸は2つだけ**
  1. **画面下の年表バー**：最初は空。章が進むたびに項目が書き込まれ、最後に「左端の空白」が残る
  2. **「初出不明」の箱**：年表の外（長尺は画面右下）に置く木箱。日付がたどれない説の札が、ここに入っていく
  - 冒頭からラストまで、この2つが画面のどこかに必ず見えている状態にする（第1章などで主役でないときも、画面下に小さく残す）
- 注意：台本は「公開前に本人がブラウザで原文確認すべき箇所」が多い。確認の結果で台本の行が削られたり数が変わったら、**年表に置く項目・札の数・サムネの文字も同時に直す**こと（特に「2つ」）

## 0. 全体で守ること（この作品の個別ルール）

| 項目 | ルール |
|---|---|
| 子ども | 実写の子どもは使わない。生成画像は**影絵（シルエット）・切り絵調だけ**。顔・目鼻を描かない。実在の子どもに似せない（特定の子の写真を元に生成しない、名前や顔写真をプロンプトに入れない） |
| 寺社 | 籠神社・伊勢神宮・日光東照宮は**文字カードのみ**。写真・イラスト・鳥居や社殿のシルエットも出さない。不気味な加工（揺れ・ノイズ・赤い光・低音の効果音）を重ねない |
| 流産説の区間（長尺 6:14〜7:04、ショート 0:25〜0:36） | 暗い演出をしない。画面は明るめの生成り色、BGMは薄く温かいものに。効果音なし。札の揺れ・光り・ズームなし |
| 実在の人物 | 山中直治・柳田国男・関裕二・久野俊彦などは**名前の文字カードだけ**。写真・肖像画・生成した顔は使わない |
| 書籍・データベース | 表紙・本文・図書館データベースや日文研データベースの画面キャプチャは**使わない**。書名・事例名・出典は文字で再構成する（使いたくなった場合は「8. 確認事項」へ） |
| 新聞 | 朝日新聞の紙面・ロゴは使わない。「朝日新聞の連載（1941年）」という文字カードのみ |
| ネット記事 | 実在サイトのスクリーンショットは使わない。0:50 の「まとめ記事風」は、架空の画面を自作してぼかす（実在サイトのロゴ・配色をまねない） |
| 旋律 | かごめかごめの旋律は「6. BGM・効果音」の案A／案Bのどちらかで。逆再生の音は流さない |
| 残酷な描写 | 遊女・囚人・処刑・出産に関わる人物や場面の絵は描かない。説の名前を札の文字で出すだけ |

## 1. チャンネル共通：テロップと画面の強調ルール

同日制作のきさらぎ駅・八尺様と共通で使えるよう、**チャンネル共通ルール**として書く（他2作の演出担当にも同じルールを申し送る）。

### 1-1. テロップの色と意味（毎回同じ）

| 種類 | 見た目 | 使う場面 |
|---|---|---|
| 通常（ナレーションの要点） | 白文字・黒の縁取り（暗い背景）／墨色文字・縁なし（明るい背景）。Noto Sans JP Bold | 基本 |
| 確認できた事実＋出典 | 通常テロップの下に、灰色の小さい文字で「出典：〜」。画面左下の決まった位置 | 図書館回答・事典・公的資料 |
| 噂・説 | 文字の下に**柿色（#C8743A）の下線**。末尾に「〜という説」「〜と言われています」を必ず入れる | 怖い説・謎の説すべて |
| 未確認 | **黄色の付せん（#E9C46A 地・黒文字）「未確認」**を項目の右上に貼る | 原文未確認の話（3:42、8:23 など） |
| 推測 | 灰色（#7A7A7A）の小さなラベル「推測」をテロップの左に付ける | 4:08、10:27、11:47 など |
| 学説（怖い噂ではない説明） | **藍色（#2F4A6D）**の下線・札 | 神寄せ・地蔵遊び起源（10:00〜10:27） |
| 問いかけ・フック | 画面中央に大きく。白（暗背景）／墨（明背景） | 0:00、5:19、8:56、12:08 など |
| 数字の強調 | 黄色（#E9C46A）で大きく | 5:32 の「2」、9:19 の「4件」 |

### 1-2. 出し方

- 出る：0.2〜0.3秒のフェード（または左から右へ短いワイプ）。ポップ・弾む動きは使わない
- 消える：0.2秒のフェード
- 揺れ・ノイズ（グリッチ）は「宙に浮いた説の札」の演出だけに限定。**寺社名・流産説・遊女説・囚人説のテロップと札には使わない**
- 1画面のテロップは2行まで。長い出典は2枚に分ける
- 長尺：年表バーが画面下（下から0〜11%）にあるので、テロップは**下から13〜28%の帯**に出す。出典表示は年表バーのすぐ上の左端
- ショート：上下の UI に隠れないよう、テロップは**画面の上から20〜65%**に収める（目安。下20%・右端15%は避ける）

### 1-3. 年表と札の色（画面の部品）

| 部品 | 見た目 |
|---|---|
| 年表バー | 1本の細い線＋目盛り。暗背景では生成り色、明背景では墨色。左端「江戸」、右端「現在」 |
| 記録カード（史料・図書館回答・事典・書誌） | 生成り地（#F1E9DA）・墨文字・細い墨枠の長方形 |
| 説の札（怖い説・謎の説） | 柿色（#C8743A）地・白文字の荷札形。**赤（血の色）は使わない** |
| 学説の札 | 藍色（#2F4A6D）地・白文字。年表の上ではなく、**年表の下の別の段**に置く（怖い説の札と並べない） |
| 未確認の付せん | 黄色（#E9C46A） |
| 「初出不明」の箱 | 素朴な木箱（生成画像 P05 を切り抜き）。ふたに墨文字で「初出不明」（文字は編集ソフトで載せる） |
| 作者欄 | 年表の左端に、記録カードと同じ見た目で「作者：　　」（空白）。最後まで空白のまま |

### 1-4. 全体の色味

- オープニング・ラスト：墨黒（#141414）の背景に生成り色の線
- 本編（調べもの・記録の場面）：生成り色の和紙調背景。明るめ
- 影絵の場面：夕暮れの橙〜薄紫のグラデーション（くすませる。ホラー調の青緑・赤は使わない）
- 流産説の区間：本編よりさらに少し明るい生成り

## 6. BGM・効果音

### 6-1. かごめかごめの旋律について（必ず読む）

- **権利は未確定**：伝統的な歌詞・旋律がパブリックドメインだと公的機関が明言した資料は見つかっていない（`02_リサーチ.md` 6章）。作者不明で江戸期からの伝承なので権利が残っている可能性は低いと見込まれるが、**確定はしていない（未確認）**
- **既存の音源・既存の編曲の権利も未確認**：市販CD・配信音源などの既存録音には著作隣接権が関わる。現代の出版楽譜の編曲部分にも権利がありうる。JASRAC の作品データベース（J-WID）での登録状況も未確認
- 既存の音源・既存の編曲譜・他人の演奏動画からの抜き出しは**使わない**
- 伝統的な旋律でも、他人の録音と照合されて自動の権利主張を受ける可能性がある（一般論としての懸念。この作品で実際に起きるかは未確認）

## 9. 「改変・合成コンテンツ」の開示について

- **この演出プランどおり（影絵・切り絵調・平面イラスト・図解・文字カードのみ）なら、開示は原則不要の見込み**。明らかにイラスト・アニメーションと分かる表現で、実在の人物・場所・出来事を本物のように見せるものではないため
