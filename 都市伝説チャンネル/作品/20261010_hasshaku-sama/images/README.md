# 八尺様：動画用の画像と下書き動画

**生成AIは使っていない**。すべてコード（HTML/SVG）で描いた自作素材で、権利は本人。影絵・切り絵・水彩・墨のにじみ風の非写実の絵と図解だけで、写真のように見える画像は含まないので、これらの画像について YouTube の「改変・合成コンテンツ」の開示は不要の見込み（最終判断はアップロード前に公式ヘルプで本人が確認）。

- テロップは画像に焼き込み済み。動き（書き順・下線・札が付く・影が横切る）は編集ソフトで付ける
- 背景イラストの左下に「※イメージ（イラスト）」と入れた。演出書は「※イメージ（生成画像）」としていたが、生成AIを使っていないので表記を変えた。**06_編集長判断.md の概要欄の一文（「画像生成AIで作ったイメージです」）も、この素材を使うなら「イラストで作ったイメージです」に直す必要がある**
- 八尺様は顔・髪・服の形のない、輪郭のにじむ影だけ。帽子は描かない（G01 の塀の上の「つばの影」だけ演出書の指定どおり）。白い服の色は 6:45（L26）以降だけ
- 掲示板は架空の画面（投稿者名・日付・本文なし。スレッド名だけ文字で重ねた）。元スレ・記事・Snopes の画面は作っていない。『秉穂録』は文字だけで、読みは出していない
- 画像の文言は台本・演出の最新版（修正履歴、06_編集長判断の 6-F 指摘4「1998年（英語圏のブログの読み取り）」まで反映）に合わせた。**原文確認で台本を直したら、build.mjs の該当行を直して作り直す**
- 右上の常駐チェックリストは時刻に応じて自動で変わる（6:45〜②・7:35〜③・7:50〜⑤ に鉛筆の「？」、8:15〜⑥に保留の札、9:52〜⑥が2段の札）。`build.mjs` の `resState` で変えられる

## 作り直し方
```
sh ../../../素材/fonts/fetch.sh   # 初回だけ（フォント取得）
node build.mjs                     # 画像をすべて書き出す（約2分）。一部だけなら ONLY=L4 node build.mjs
python3 make_video.py              # 下書き動画を作る（約2分）
```
- ⑥の判定が変わったとき（86783 の原文確認）：`build.mjs` の `MK`（答え合わせの記号）、`hold`（保留の札）、サムネA の `checklist({ ... hold: 1 ... })`、ショート S07 の `cover` を直す
- 7:05〜7:15（白い喪服）を削るとき：04_演出.md の行を消すとカットの番号がずれるので、`make_video.py` の `CHAPTER`・`SPLIT` と `build.mjs` の L27 以降の番号も合わせる
- 共通ツール（`素材/tools/`）は import して使うだけで変えていない。この回専用の背景・部品はすべて `build.mjs` の中にある
