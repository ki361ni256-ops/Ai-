# きさらぎ駅：動画用の画像と下書き動画

**生成AIは使っていない**。すべてコード（HTML/SVG）で描いた自作素材で、権利は本人。写真のように見える画像は含まないので、これらの画像について YouTube の「改変・合成コンテンツ」の開示は不要の見込み（最終判断はアップロード前に公式ヘルプで本人が確認）。

## 中身
| フォルダ | 中身 | サイズ |
|---|---|---|
| `long/` | 長尺のカット L01〜L86（04_演出.md のカット表どおり）。章タイトルは `L14a` `L24a` `L39a` `L48a` `L59a` `L68a`、`L11b` は L11 の後半 | 1920×1080 |
| `short/` | ショートのカット S01〜S10（S05 は a/b/c の3枚） | 1080×1920 |
| `thumb/` | サムネ案 A「結末がない」・B「分単位の記録」・C「読み手も作った？」 | 1280×720 |
| `bg/` | 背景イラスト G01〜G09（テロップなし。編集で自由に使う）と縦版 | 1920×1080 / 1080×1920 |
| `video/` | 下書き動画（音なし）。カット表の時間どおりに静止画を並べたもの。長尺 15分10秒・ショート 1分 | mp4 |

- テロップは画像に焼き込み済み。動き（ズーム・フリップ・札が付くアニメ）は編集ソフトで付ける
- 背景イラストの左下に「イメージ（イラスト）」と入れてある（再現イメージであることを示すため）
- 画像の文言は台本・演出の最新版（再チェック後の修正込み）に合わせた。**原文確認で台本を直したら、build.mjs の該当行を直して作り直す**

## 作り直し方
```
sh ../../../素材/fonts/fetch.sh   # 初回だけ（フォント取得）
node build.mjs                     # 画像をすべて書き出す（約1分）
python3 make_video.py              # 下書き動画を作る（約2分）
```
- 23:14／23:23 の対応や、黄の札を白「確認済」に変えるときは `build.mjs` の Lshape（整理パート）と `tag('check')` を `tag('ok')` に変える
