# 品質基準（チェック担当が各1〜5点で採点）

| # | 項目 | 5点の状態 |
|---|---|---|
| 1 | フック | 冒頭3秒で「続きが気になる」問いか映像がある |
| 2 | 新しさ | 定番ネタでも、元ネタ・広まり方・反証など、よくある動画にない切り口がある |
| 3 | 正確さ | 断定はすべて出典つきの事実。噂は噂として語っている |
| 4 | テンポ | 長尺は章ごとに次への引きがあり、中盤に再フックがある。水増しがない。ショートは1文が短く、5秒以上の間延びがない |
| 5 | オチ | 最後に余韻・ひねり・問いかけがあり、コメントしたくなる |
| 6 | 映像の指示 | 全カットに画面指示があり、素材の権利が確認済み |
| 7 | タイトル・サムネ | 本編で回収できる範囲で、クリックしたくなる |

- 合計 28点以上：公開OK の目安／21〜27点：改善してから／20点以下：作り直し
- ただし、チェック項目1〜8（事実と噂・名誉・被害者・誤情報・著作権・開示・危険）に NG があれば点数に関係なく NG
- 公開後は、再生数・視聴維持率などの実績（本人が YouTube Studio で確認した数字）を `ネタ帳.md` の「学び」に書き、基準の見直しに使う

## 完成動画の最終チェック（本人に渡す前に必ず）
- 書き出した動画の最初の画面・章の変わり目・最後の画面を画像で取り出して目で見る（チェック担当の決まり）
- ショートには章名・作業用の文字を出さない。長尺の章名は台本の章と合っていること
- 2026-10-11 八尺様ショートで、見出し「台本」が画面に出たまま渡した。以後この確認を省略しない
