# 収益化プラン（目標：月3万円）

作成 2026-10-10。**目標であって保証ではない**。数字はすべて仮定か、要確認のもの。実績は本人が YouTube Studio などで確認した数字だけで評価する。

## 1. 収入源と始められる時期
| 収入源 | 始められる条件 | 時期の目安 |
|---|---|---|
| 概要欄のアフィリエイト（関連書籍・映画・原作小説など） | 楽天・Amazon 等のアフィリエイト登録。**「PR」「広告」の表記が必要**（2023年10月からのステマ規制） | 1本目から |
| YouTube 広告収入 | YouTube パートナープログラム（YPP）の条件達成（下記・要確認） | 数か月〜 |
| メンバーシップ・スーパーサンクス | YPP の条件（下の段階）達成 | 数か月〜 |
| note 等での有料記事（リサーチ資料・考察まとめ） | 動画で集まった人がいること | 視聴者がついてから |

YPP の条件（記憶による。**公開前に YouTube 公式ヘルプで要確認**）
- 広告収入あり：登録者1,000人＋「直近12か月の長尺の総再生時間4,000時間」または「直近90日のショート再生1,000万回」
- 一部の収益機能のみ：登録者500人＋直近90日に公開動画3本＋「総再生時間3,000時間」または「ショート再生300万回」

→ **長尺中心のこのチャンネルは「総再生時間4,000時間」が主な壁**。13分の動画を平均5分見てもらえるなら、約4万8千回の視聴で届く計算（平均視聴時間は仮定）。

## 2. 月3万円の目安（仮定の計算）
広告の収益は「1,000回再生あたりの収益（RPM）」で決まり、ジャンル・視聴者層・時期で大きく変わる。下は**仮の数字での計算例**で、実際の RPM は収益化後に YouTube Studio で確認する。

| 仮の長尺RPM | 月3万円に必要な長尺の再生（月） |
|---|---|
| 200円 | 15万回 |
| 400円 | 7万5千回 |
| 600円 | 5万回 |

ショートの RPM は長尺よりかなり低いとされるため、ショートは「本編への入口」として扱い、収入の柱にしない。

## 3. 制作ペース（無理なく続く量）
- **長尺：週1本**＋**その要点ショート：週1本**。余力があれば単発ショートを週1〜2本
- 1本あたりの本人作業：原文確認（30〜60分）／素材の規約確認／ナレーション（合成音声なら規約確認）／編集／アップロード
- ボトルネックは**本人の原文確認と編集**。ネタ選びの段階で「一次資料をブラウザで確かめやすいテーマ」を優先して、原文確認を軽くする
- ネタは常に4本以上ストック（ChatGPT ネタ出し → 社員チームで台本まで先に作っておく）

## 4. 伸ばすための決まり
1. **サムネとタイトル**：3案から選び、反応が悪ければ公開後に差し替える（Studio のクリック率を見る）
2. **最初の30秒**：視聴維持率のグラフで、落ちている秒数を毎回ネタ帳の「学び」に書く
3. **ショート → 本編**：ショートの関連動画に本編を設定（機能の有無は Studio で確認）
4. **シリーズ化**：「元の記録と後から広まった話」シリーズとして再生リストにまとめ、続けて見てもらう
5. **量産に見せない**：毎回語り口・構成を変える（同日3本で型分けした決まりを続ける）。収益化審査の「繰り返しの多い／独自性のないコンテンツ」対策
6. **アフィリエイト**：編集長が毎回、概要欄に関連書籍・作品の候補を出す（PR表記つき。紹介する作品は本人が実在を確認）
