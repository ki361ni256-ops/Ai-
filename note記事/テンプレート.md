# note記事テンプレート（煽り系・予想入り）

出走表とオッズ表（並び入り）が貼られたら、`scripts/yosou.py predict` の結果（印・買い目）をもとに、この型で書く。
印・買い目は**仕組みが出したものをそのまま使う**（記事のために変えない）。

## 書き方のルール
- 熱量は上げてよい。ただし言うのは「見どころ」と「狙い」。「当たる」「勝てる」「儲かる」「必ず」「絶対」「確実」「鉄板」は書かない（CLAUDE.md・景品表示法の有利誤認の心配）
- 「AI予想」と書かない。「出走表とラインから読む予想」
- オッズを見ていないときは「荒れる」「堅い」「妙味」を書かない。オッズがあるときは、実際の数字で煽る（例「本命サイドでも 4-3-1 は12.8倍つく」）
- 実績は**記録にある数字だけ**。盛らない・作らない（例：弥彦 10/9 は 5R中1的中・回収率55%。書くならそのまま）
- 展開は、並び・競走得点など**分かっている情報だけ**から書く。脚質・調子を想像で作らない
- 買い目は「厚め・本線・押さえ」の3区分だけ、フォーメーション表記（1-25-25）
- 有料部分にするなら、無料部分に「何R・何点・どの区分か」を正直に書く（中身を誇張しない）
- 書いたらチェック担当（keirin-checker）に禁止語・買い目の一致を確認してもらう

## 型

```
タイトル：【<会場><R>R】<一言フック（並び・得点差など事実ベース）>

<つかみ 2〜3行：このレースのどこが面白いか。数字か並びで>

■ 並び
<並び>  ※オッズパーク <時刻>現在の表示

■ 見どころ
<ライン同士の力関係・得点トップの位置・単騎の動き。事実から>

■ 印
◎<> ○<> ▲<> △<> △<>
<◎の根拠を1〜2行（競走得点・ライン位置）>

――――― ここから有料（任意） ―――――

■ 3連単
厚め　<>
本線　<>
押さえ　<>
（計<n>点）

■ オッズ（<時刻>現在）
<買い目の主なオッズ。見ていなければ書かない>

■ ひとこと
<締めの煽り。期待と熱量。ただし結果の約束はしない>

※過去の結果は将来の的中・利益を約束するものではありません。車券はご自身の判断で。
```

最後の1行は note（記事・有料販売）用。X の投稿文には入れない（2026-10-09 本人指示）。
