# note記事（悩み解決 → 楽天ROOMへ）

2026-10-04 本人方針: 以前「心がすり減っている人向け」に書いていたnoteアカウントを、完全に方向転換する。困っている人の悩みを解決する無料記事を書き、記事の最後に楽天ROOM（コレクション）のリンクカードを置いて、収益につなげる。

## 仕組み
```
noteの無料記事で悩みに答える
  ↓ 記事の最後に「ROOMに載せてます」のリンクカード
楽天ROOMのコレクション → 商品ページ → 購入 → 報酬
```
- 参考: 他の人のnoteでも、記事の最後に「#楽天ROOMに載せてます」の見出しを置き、ROOMのURLを貼ってリンクカードにしている
- リンク先は、まず **ROOMのコレクション**（悩みごとにまとまっているので、記事とつなげやすい）。商品1つを詳しく紹介するときだけ、商品のリンクも貼る

## 方針
- ジャンル: ROOMと同じ「子育て・暮らし・30代後半パパ」の悩み（`02_plan/nayami-list.md` をそのまま使う。ROOMに商品がもうあるので、記事を書けばすぐつながる）
- 書き手: タクロウ🦉（2026-10-04 本人決定。Threads・ROOMと同じ名前。プロフィールは `プロフィール.md`）
- 1記事 = 1つの悩み（または1つの場面）× 商品3つくらい。タイトルに「誰の・どんな悩み」を入れる
  - 例: 悩み型「食べこぼしの片付け」→ 食器・マット・エプロン／場面型「子連れのおでかけ」→ バッグ・ワゴン・レジャーマット

## 守ること（CLAUDE.md の作業ルールと同じ）
- **記事の最後、ROOMリンクのすぐ上に PR表記**（2026-10-04 本人判断。リンクのすぐ近くに置き、小さくしない・見落とされる場所に置かない。記事の途中に商品リンクを貼るときは、各リンクに「楽天ROOMで見る（PR）」と付ける）:「PR：この記事には楽天アフィリエイトの広告リンクが含まれています」（note公式は「PR」「広告」「プロモーション」など分かりやすい表示をすすめている）
- 使っていない商品を「使ってよかった」と書かない。紹介は「レビューでは〜」で書く（`guidelines/review-summary.md`）。使用感は `【要記入: 自分の使用感】`
- 効果効能を言い切らない（薬機法）。最安・1位・価格・クーポンは書かない
- 商品は「選択肢の1つ」。「これがないとダメ」と不安をあおらない
- 「必ず効果がある」「絶対に失敗しない」「販売実績No.1」「最安」など、根拠のない・実際より良く見せる表現は使わない
- 自分のリンクを自分でクリック・購入しない。スパム的な貼り方（同じリンクの連打・記事と関係ない商品）もしない

## noteで楽天アフィリエイトを使ってよいか（2026-10-04 確認）
本人がChatGPTで調べ、公式ページのURLを本人が確認（2026-10-04）。内容の要約はChatGPTの説明による（この作業環境からはnote.comに接続できず、Claudeは本文を直接確認できていない）。規約は変わるので、記事を書き始める前と、半年に1回くらい開き直す。
| 内容 | 出典 | 日付 |
