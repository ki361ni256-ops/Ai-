# note記事（悩み解決 → 楽天ROOMへ）

2026-10-04 本人方針: 以前「心がすり減っている人向け」に書いていたnoteアカウントを、完全に方向転換する。困っている人の悩みを解決する無料記事を書き、記事の最後に楽天ROOM（コレクション）のリンクカードを置いて、収益につなげる。

## 仕組み
```
noteの無料記事で悩みに答える
  ↓ 記事の最後に「ROOMに載せてます」のリンクカード
楽天ROOMのコレクション → 商品ページ → 購入 → 報酬
```
- 参考: 他の人のnoteでも、記事の最後に「#楽天ROOMに載せてます」の見出しを置き、ROOMのURLを貼ってリンクカードにしている
- リンク先は、まず **ROOMのコレクション**（悩みごとにまとまっているので、記事とつなげやすい）。商品1つを詳しく紹介するときだけ、商品のリンクも貼る

## 方針
- ジャンル: ROOMと同じ「子育て・暮らし・30代後半パパ」の悩み（`02_plan/nayami-list.md` をそのまま使う。ROOMに商品がもうあるので、記事を書けばすぐつながる）
- 書き手: 【要記入: noteの名前をタクロウにそろえるか、別の名前にするか】
- 1記事 = 1つの悩み。タイトルに「誰の・どんな悩み」を入れる

## 守ること（CLAUDE.md の作業ルールと同じ）
- **記事の冒頭に PR表記**:「※この記事には楽天アフィリエイトのリンクを含みます」
- 使っていない商品を「使ってよかった」と書かない。紹介は「レビューでは〜」で書く（`guidelines/review-summary.md`）。使用感は `【要記入: 自分の使用感】`
- 効果効能を言い切らない（薬機法）。最安・1位・価格・クーポンは書かない
- 商品は「選択肢の1つ」。「これがないとダメ」と不安をあおらない
- noteのアフィリエイトリンクのルールは、noteのヘルプで確認してから始める（確認日: 【要記入】）

## 古い記事の扱い
- 削除すると元に戻せない。残したい文章があれば、消す前にコピーして手元に保存しておく
- プロフィール（名前・自己紹介・アイコン）も新しい方向に合わせて変える

## ファイル
- `_template/article.md` … 記事の型（コピーして `YYYY-MM-DD_slug.md` を作る）
- `記事ネタ.md` … 書く予定の悩み一覧
