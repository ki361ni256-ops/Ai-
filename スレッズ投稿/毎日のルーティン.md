# Threads 毎日のルーティン（1日20〜30分）

方針は `成長戦略.md`（初期フェーズ）。

フォロワーを増やすための「毎日やること」をこれだけに絞る。迷ったらこのファイルを上から順にやる。

## 朝（5分）
- [ ] **お弁当の写真を1枚撮る**（詰め終わったところ。写真つき投稿は目に止まりやすい）
- [ ] 朝の投稿を **7〜9時** に出す（予約済みなら確認だけ）。投稿したら **15〜30分はアプリを開いておき**、返信には早めに返す。写真があれば「今日のお弁当」シリーズで出す（下の型）
- [ ] トピック（タグ）を1つ付ける：`子育て` `お弁当` `パパ育児` など

## 昼休み・通勤（10分）
- [ ] **返信を10件以上**（朝・昼・夜に分けてもOK）：下の「探すことば」で検索 → 投稿から1時間以内・返信がまだ少ない投稿を選ぶ → Gemini の「へんしん1〜3」で作って、1か所だけ自分の言葉に直して送る
- [ ] 自分の投稿に来た返信には **全部返す**（お礼＋ひとこと＋質問）
- [ ] 返信でやり取りした人のうち、子育て・パパ・カメラの人を **2〜3人フォロー**

## 夜（5分）
- [ ] 夜の投稿を **21〜23時** に出す。出したあと15〜30分は返信に備える
- [ ] `反応ログ.md` に今日の数字を1行だけ書く（閲覧数・いいね・返信・フォロワー数）

## 探すことば（返信先を見つける）
- 子育て：`夜泣き` `寝かしつけ` `イヤイヤ期` `3歳` `ワンオペ` `保育園`
- パパ：`パパ育児` `育休パパ` `共働き` `お弁当 パパ`
- 暮らし：`お弁当` `作り置き` `朝ごはん`
- カメラ：`子ども 写真` `一眼 子ども` `カメラ初心者`

## 「今日のお弁当」シリーズの型（毎朝の定番にする）
写真＋本文（短くてよい。シリーズは「この人いつもいるな」と覚えてもらうためのもの）
```
今日のお弁当。自分の分と、妻の分。【おかずを1〜2個】。平日の朝は朝ごはんとお弁当2つ、2児のパパの日課です。【ひとこと：今日の工夫・失敗・子どもの一言など】
```
- 毎日同じ書き出しにすると、シリーズとして覚えてもらいやすい
- コメント欄はなしでもOK。ある日は「詰め方」「時短のコツ」を書く

## やらないこと
- 相互フォローのお願い・一気に大量フォロー（スパム扱いのおそれ）
- 同じ文章のコピペ返信
- 他人の投稿にリンクや宣伝
