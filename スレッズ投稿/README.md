# スレッズ投稿

Threads（@takurou_kurashi・タクロウ）の投稿文を置くフォルダです。

- 1投稿 = 1ファイル。ファイル名は `YYYY-MM-DD_内容.md`
- 新しい投稿は `_template.md` をコピーして作る
- 投稿したら `投稿済み/` に移動し、反応（いいね・返信・プロフィールへのアクセス）を書き足す

## ルール
- ROOM・商品のリンクを貼る投稿には「※楽天アフィリエイトを利用しています」を付ける
- 使っていない商品を「使ってよかった」と書かない（欲しいものは「気になっている」）
- 想像で書いた体験は投稿前に本人が確認・修正する
- 寄り添い系の前アカウント（室長）では、このアカウントやROOMの宣伝をしない
